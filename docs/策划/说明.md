# 策划文档

游戏玩法与内容的共识记录。未 grilling 的子系统只记账，不写实现。

## 和另外两套文档的边界

| 目录 | 写什么 |
|------|--------|
| `docs/架构/` | 框架怎么用（启动、生命周期、进度） |
| `docs/框架设计讨论/` | 框架为什么这么做 |
| `docs/策划/` | 这款游戏是什么、首版做哪些 |
| `docs/素材/` | 像素素材外部工具备查（未锁定，见 [像素素材工具推荐](../素材/像素素材工具推荐.html)） |

数值、格子边长、默认 cell 宽高、扩张消耗等 **全部配表**，本文不写死数字。
