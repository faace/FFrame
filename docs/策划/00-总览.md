# 总览（已锁定）

Steam 挖矿挂机。卖点：矿体是异形窗，每个玩家因扩张选择长成不同外形。

## 核心循环（首版）

开井 → 工人自动挖 → 选扩张 → 主线涨级 → 离开再回来收离线。

- 地面一块 cell，带矿井框。点井后在正下方长出第一块地下 cell，梯子连到地面。
- 未挖开区域由许多格子组成。开局 1 个工人，按固定队列一次挖一格（从梯子 / 井壁往外扫，规则可配）。
- 格子当怪物（血量、防御）；工人 / 稿攻击它，格子不还手。伤害公式暂用比例式，细调后 grilling。
- 一格进度、间隔、加成都不写死，读配表。技能 / 道具等加成来源首版不做成系统。
- 挖空某一侧后，可往左 / 右 / 下扩（不互斥，也可先不扩）。条件：资源（种类 + 数量）+ 玩家等级 + 该侧是否必须已挖空。
- 等级 = 整局玩家等级，不是工人等级。首版经验来自挖格子和主线；副本只留来源枚举。
- 收获、加工、钱、商店、任务物品 → 标成「收获与经济」，后 grilling。
- 首版有离线收益；怎么算后 grilling。
- 工具首版只当挖速等加成入口，升级树后做。多工人同时领队头：模型预留，首版不招人。

格子大小、默认 cell 空间（曾暂定 6×3、64 像素）均可配，按手感再改。

## 窗口（已锁定）

- 矿（地面 + 地下）是一扇可拖的异形窗，外形 = 已有 cell 的并集。
- 不打扰：只显示地面，默认可放右下；点开看全貌。
- 不定死整局游戏分辨率。窗有多大，逻辑分辨率就设成多大（1 单位 = 1 像素）。矿按格子像素，弹窗按面板自己的宽高。不用手机那套固定 1080p 适配。
- 发布走 **Electron 真双窗**（Creator 3.8 不能从 TS 再开第二扇操作系统游戏窗）：
  - 矿窗：无边框透明，唯一跑模拟和落盘，是 `gd` / `gl` 的权威。
  - UI 窗：一扇标准窗；设置 / 主线 / 背包全部居中；叠加走 Cocos layer 栈。
- 两扇都是同一份 Creator Web、同一套素材。弹窗只显示、只发指令；改设置必须回矿窗。
- 两窗可同时看见。不做贴靠弹窗。不做「角落矿 + 屏幕中央面板」拼成一张大透明画布。
- 透明、点穿、DPI 属平台细节，后grilling。
