# 05 游戏侧接入

## 目标

游戏的 `bundles/Skin` 改成按主题组织：旧图移入 `LegacyV3/`，新图放进 `ZooV7/`，去掉预制体里的 uuid 图标引用，`SkinKit` 迁移，切换主题可用。

## 范围（文件/目录）

- `FFrame/assets/game/bundles/Skin/LegacyV3/`：把现在 `bundles/Skin/` 下的 27 张 png 和它们的 `.meta` 整体移入。
- `FFrame/assets/game/bundles/Skin/ZooV7/`：放 `ctrl.png`、`ctrl.json`、`item.png`、`item.json`（来自 02、03 的成品）。
已核实：下面三处直接用 uuid 引用了旧的 png，改成代码按名取。

- `FFrame/assets/game/bundles/GameUI/LyAlert.prefab`：引用 `icon_close`、`panel`。
- `FFrame/assets/game/bundles/Demo/DemoHome/LySetting.prefab`：引用 `btn_primary`、`btn_secondary`、`icon_close`、`icon_help`、`icon_plus`。
- `FFrame/assets/game/bundles/Demo/DemoHome/ScDemoHome.scene`：引用 `btn_primary`、`btn_secondary`、`btn_warning`、`btn_neutral`、`btn_info`、`tab_normal`、`tab_selected`、`icon_ad`、`icon_gold`、`icon_diamond`、`icon_energy`（这一处改动最多，需要单独检查）。
- `FFrame/assets/game/bundles/GameUI/SkinKit.ts`：`SLICED` 名单和 `skinFrame` 改成对接 04 的新接口，或者删掉，改用框架的 `skinFrame`。
- `LySetting.ts`：`icon_music`、`icon_sfx`、`icon_settings` 等已经在代码里按名取，不需要改，只检查一次。
- `FFrame/assets/game/config.ts`：如需要，加当前主题名配置（例如 `skinTheme: 'ZooV7'`）。

## 验收标准

- [x] `bundles/Skin/LegacyV3/` 下有旧的 28 张图和 `.meta`，`bundles/Skin/` 根下没有散落的 png。票面写 27，目录里实际是 28。
- [x] `bundles/Skin/ZooV7/` 下有 `ctrl.png`、`ctrl.json`、`item.png`、`item.json`。
- [ ] `LyAlert`、`LySetting` 预制体里没有直接引用 png 的 uuid 图标，图标由脚本按名取。uuid 还留着，免得编辑器丢资源；运行时 `redress` 按旧 uuid 换成当前主题。
- [ ] 切换主题名（`config.ts`）后，`LegacyV3` 和 `ZooV7` 都能正常显示，没有白块。代码已接上，预览未跑。
- [ ] 按钮、面板、tab、滑条、进度条、步进、标题在 `ZooV7` 下显示正常，尺寸和以前一致（按 2 倍规则换算后）。预览未跑。
