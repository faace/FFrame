# 05 游戏侧接入

## 目标

游戏的 `bundles/Skin` 只保留 `ZooV7/` 一套 plist 图集。预制体和场景里的图标引用换成 `ZooV7` 子图的 uuid，`SkinKit` 去掉旧图映射，`config.skinTheme` 切主题可用。旧的 `LegacyV3` 逐张图已退役。

## 范围（文件/目录）

- `FFrame/assets/game/bundles/Skin/ZooV7/`：`ctrl.png`、`ctrl.plist`、`item.png`、`item.plist`（来自 02、03 的成品）。
- `FFrame/assets/game/bundles/Skin/LegacyV3/`：已整体移出到 `FFrame-asset-line/legacy/Skin-LegacyV3-game/`（含 `.meta`），游戏运行时不再加载。
- 预制体、场景的图标 uuid：`LyAlert.prefab`、`LySetting.prefab`、`ScDemoHome.scene`、`LyButtons.prefab` 里原来指向旧逐张图的 uuid，已用 `del/替换皮肤引用/替换.mjs` 换成 `ZooV7` 子图 uuid，共 37 处，`--check` 残留 0。
- `FFrame/assets/game/bundles/GameUI/SkinKit.ts`：删掉 `LEGACY_SLOT` 旧图映射和 `redress`。`loadSkin` 仍走框架，传 `config.skinTheme`。
- 调用 `redress` 的四处（`LyButtons.ts`、`LySetting.ts`、`ScDemoHome.ts`、`LyAlert.ts`）：删掉 import 和调用。
- `FFrame/assets/game/config.ts`：`skinTheme: 'ZooV7'`，注释改为只认 plist 主题。
- 框架 `gmajor/ui/GMSkin.ts` 版本升到 0.6.0（见 `CHANGELOG.md`）。
