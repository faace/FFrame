# 03 物品图集

## 目标

生成 `ZooV7/item.png`（2048×2048）和 `item.json`，8 个图标统一放在 128×128 格子里。

## 范围（文件/目录）

- `D:\creator\FFrame-asset-line\style\ZooV7\物品\`：`prompt.md`（引用 `style.md`）、`history/`、`item.png`、`item.json`。

## 验收标准

- [x] `item.png` 是 2048×2048，透明底。边缘浅底已抠掉，个别图标自己带的浅色底板还在。
- [x] 8 个图标：`icon_gold`、`icon_diamond`、`icon_energy`、`icon_ad`、`icon_music`、`icon_sfx`、`icon_settings`、`icon_play`。另外 20 个常用槽也放进去了。
- [x] 每个图标都在 128×128 的格子里，图标本身居中，不超出格子。
- [x] `item.json` 每个槽都有 `rect`，格子大小一致（都是 128×128）。
- [ ] 图标是画出来的物件（金币、宝石、闪电这一类），风格跟 `style.md` 和 v7 母版里的物品图标走。先用这版，后面再改出图。
- [x] `history/` 记录了每个版本的提示语、参数、结论。
