# 02 控件图集

## 目标

生成 `ZooV7/ctrl.png`（2048×2048）和 `ctrl.json`，包含 20 件控件和约 10 个预留空槽。

## 范围（文件/目录）

- `D:\creator\FFrame-asset-line\style\ZooV7\控件\`：`prompt.md`（引用 `style.md` 的风格块）、`history/`（每个版本一个子目录，记录提示语、参数、参考图、输出、结论）、`ctrl.png`、`ctrl.json`。
- 只写素材仓库，不改 `FFrame` 和游戏代码。

## 验收标准

- [x] `ctrl.png` 是 2048×2048，透明底，所有空白像素 alpha = 0。
- [x] 名单上的件全部在图上，且互不接触、互不重叠，间距大于 24 像素。票面写 20 件，名字数一遍是 21 件，21 件都画了。
- [x] 预留 10 个空槽，位置在 `ctrl.json` 里标明为 `reserved`。
- [x] `ctrl.json` 里每个槽都有 `rect`、`border`、`sliced`，`border` 单位是源图像素。
- [x] 尺寸符合 2 倍规则：源图按 2 倍出，九宫格 `border` 是显示值的 2 倍。
- [x] `history/v8` 有参数和结论，最终采用版在 `prompt.md` 里标明。
- [x] 槽名与清单一致：`btn_primary`、`btn_secondary`、`btn_warning`、`btn_neutral`、`btn_info`、`title_bar`、`panel`、`tab_normal`、`tab_selected`、`slider_track`、`slider_thumb`、`progress_fill`、`bar_bg`、`bar_fill`、`stepper_plate`、`slot_item`、`frame_select`、`icon_close`、`icon_help`、`icon_plus`、`icon_minus`。
