# 06 动物园素材入库

## 目标

`FFrame-zoo/资源生成/`（约 193MB，523 个文件）用 Git LFS 入库，换电脑 clone 后能拿到素材。

## 范围（文件/目录）

- `FFrame-zoo/.gitignore`：去掉 `资源生成/` 这一行。
- `FFrame-zoo/.gitattributes`：加 LFS 规则，至少覆盖 `资源生成/**/*.png`。
- `FFrame-zoo/资源生成/`：里面的文件按 LFS 入库。

## 验收标准

- [ ] `git lfs version` 能跑（本机已装 3.5.1）。
- [ ] `git lfs track` 后，`.gitattributes` 里有对应规则。
- [ ] `git lfs ls-files` 能列出 `资源生成/` 下的大图。
- [ ] `FFrame-zoo` 现有的 5 个未提交改动（`ZooHome/HomeHud.ts`、`ZooFont.ts`、`ZooLayer.ts`、`settings/v2/packages/information.json`、策划文档 `16-弹窗骨架.md`）没有被提交。
- [ ] `FFrame-zoo/del/`（36MB，506 个文件）仍然不入库，`.gitignore` 里的 `/del/` 不变。

无

- 不提交 zoo 的 5 个未提交改动，它们要单独处理。
