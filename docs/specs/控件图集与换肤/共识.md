# 控件图集与换肤 共识

## 目标

把游戏里现在 27 张独立的 `Skin` 小图，换成按主题组织的两张 2048×2048 图集（控件一张、物品一张），并用一份清单描述每个槽位的位置和九宫格。以后换风格只新建一个主题文件夹，不改代码。素材的提示语、版本过程和最终采用版本，全部入库到 `FFrame-asset-line`，换电脑后可以继续。

## 已定决策

1. **工作流**：大路径。grilling → `共识.md` → 你确认 → `/spec` 拆 ticket → 你确认 → 每条 ticket 用 `/implement NN` 单独开 session → `/review`。
   - 理由：涉及框架 `gmajor`、游戏 `bundles/Skin`、素材仓库、动物园素材，跨多个模块。

2. **母版风格**：`ui-sheet-v7`。
   - 理由：提示词里写明 "same pixel craft as the zoo map"，最新一版，和动物园母图对齐。

3. **分两步做，各一张图集**：先做控件图，后做物品图；控件和物品不共用一张图，各 2048×2048。
   - 理由：两步互不影响，换肤可以只换其中一张。

4. **换肤方式**：每套主题一个文件夹，运行时按主题名加载。
   - 理由：换风格只改主题名，代码不动。

5. **素材仓库**：`FFrame-asset-line`，按 `style/<主题>/` 组织。
   - 理由：已经是独立的 GitHub 远端仓库，`style/` 和 `scripts/` 已入库，换电脑 clone 即可。

6. **风格提示语**：共用的风格块（STYLE、CAMERA、LIGHTING、配色、描边）写在每个主题的 `style.md` 里，控件和物品两步都引用它。
   - 理由：改风格只新建主题，旧主题的提示语不会被改坏。

7. **提示语记录**：每一步的 `prompt.md` 记录完整提示语原文、生成参数、参考图路径。

8. **过程记录**：每一步下有 `history/`，每个版本一个子目录，内容包括提示语、参数、参考图、输出图、结论（采用或放弃，并写明原因）。最终采用的版本在 `skin.json` 里标记。

9. **动物园素材**：`FFrame-zoo/资源生成/`（约 193MB）用 Git LFS 入库。
   - 理由：本机已装 Git LFS 3.5.1，可以直接用。

10. **尺寸基准**：按设计分辨率 720×1280 的 2 倍出图，运行时显示为 1/2。
    - 理由：动物园母图是 1440×2560，正好是 2 倍，比例是整数，像素最清楚。

11. **控件清单（20 件）**：
    - 5 个按钮底板：`btn_primary`、`btn_secondary`、`btn_warning`、`btn_neutral`、`btn_info`
    - 标题条 `title_bar`、面板 `panel`
    - 2 个 tab：`tab_normal`、`tab_selected`
    - 滑条：`slider_track`、`slider_thumb`
    - 进度条 `progress_fill`、经验条 `bar_bg` / `bar_fill`
    - 步进底板 `stepper_plate`
    - 格子 `slot_item`、选中框 `frame_select`
    - 按钮上的小图标 4 个：`icon_close`（X）、`icon_help`（问号）、`icon_plus`、`icon_minus`
    - 另外预留约 10 个空槽，给以后要加的开关、复选框、输入框、Toast 底板、角标、下拉框、滚动条用。
    - 理由：按钮、tab、滚动条、面板这些才是控件；按钮上的 X、问号、加号、减号是按钮的图标，也归控件文件。

12. **物品图标（物品文件）**：金币、钻石、能量、广告、音乐、喇叭、齿轮、播放三角（游戏里暂未用到）。
    - 所有图标统一格子大小：128×128 源图，运行时显示为 64×64。
    - 理由：统一格子后，同一个 `PfGMBtn` 或资源条放不同图标时尺寸一致。

13. **扩充空位**：控件图预留约 10 个空槽。

14. **旧 Skin 处理**：现在的 `bundles/Skin`（48 像素逐张图）整体移成一个旧主题文件夹保留，新主题放在它旁边，可以回退。

15. **游戏侧结构**：`bundles/Skin/<主题>/` 下放最终采用的控件图、物品图及各自的清单，运行时只按主题名切换。

16. **del/ 处理**：`FFrame/del/` 保留在本地，不删除，也不整夹迁移。`/del/` 已在 `FFrame/.gitignore` 里生效。需要留存的素材和脚本才迁到 `FFrame-asset-line`，`build/` 留在本地 `del/` 里不迁移。

17. **主题目录名**：`ZooV7`（当前主题）和 `LegacyV3`（旧主题）。英文大驼峰，符合 `01-naming` 的命名约定。
    - 理由：游戏里 Bundle 和目录名要符合命名规范，不用中文和连字符。素材仓库里也用同样的名字，两边一致。

## 不做什么

- 不做 Toast、开关、复选框、输入框等新控件本身，只在图集里留位。
- 不改 `PfGMBtn`、`PfGMSlider`、`PfGMBar` 等控件的行为和对外接口，只改它们取图的方式。
- 不改 `FFrame-zoo` 里现有的 5 个未提交改动。
- 不迁移动物园 `ZooHome` 的代码，只把 `资源生成/` 入库。
- 不删除 `FFrame/del/build/`。
- 不改 `.cursor/rules/` 下的规则文件，规则更新要等你单独确认。

## 验收标准

- [ ] `FFrame-asset-line/style/<主题>/` 下有 `style.md`、`控件/`、`物品/`，每个子目录有 `prompt.md`、`history/`、最终图和清单。
- [ ] 控件图和物品图都是 2048×2048 透明底 PNG。
- [ ] 控件图包含 20 件，并预留约 10 个空槽。
- [ ] 物品图里每个图标都在 128×128 的格子里。
- [ ] 每个槽在清单里都有 `rect`、九宫格 `border`、显示尺寸。
- [ ] `gmajor/ui/GMSkin.ts` 能按主题名加载两张图集，`skinFrame(name)` 接口不变，原有槽名都能取到。
- [ ] 游戏里按钮、面板、tab、滑条、进度条显示正常，没有白块。
- [ ] 旧主题可以切回，显示和以前一致。
- [ ] `FFrame-zoo/资源生成/` 的大图在 LFS 里（`git lfs ls-files` 能看到）。
- [ ] `FFrame/del/` 下的内容没有遗漏迁移（`build/` 按决策 16 留在本地）。

## 涉及范围

- `FFrame/gmajor/ui/GMSkin.ts`：按主题加载图集和清单。
- `FFrame/gmajor/ui/PfGMBtn.ts`、`PfGMSlider.ts`、`PfGMBar.ts`、`PfGMTitle.ts`、`PfGMTabs.ts`、`PfGMStepper.ts`：取图方式如有变化，只改取图部分。
- `FFrame/assets/game/bundles/Skin/`：重组为 `<主题>/` 结构，旧图整体移入旧主题文件夹。
- `FFrame/docs/界面组件/`：更新皮肤和图集的说明。
- `FFrame-asset-line/style/`、`控件/`、`物品/`、`tools/`：素材、提示语、历史版本、从 `del/` 迁入的脚本。
- `FFrame-zoo/资源生成/`：加入 LFS 入库。
- `FFrame/.cursor/rules/01-naming.mdc`：旧的 48 像素、16 切边、`del/draw-*.mjs` 路径，等你确认后单独更新。
