# 单选 共识

## 目标

在框架里补一组单选：`PfGMRadioGroup` 管互斥，`PfGMRadio` 画一颗圆点。一组里只能选一个。点圆点或点这一行右边的内容，都是选中这一项。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后实现 → 验收。

2. **两个类，都有预制体**。
   - 组 `PfGMRadioGroup` / `PfGMRadioGroup.ts` / `PfGMRadioGroup.prefab`。根上只有脚本和 `UITransform`，没有皮，不挂 `Button`。组根的尺寸不是热区。
   - 单项 `PfGMRadio` / `PfGMRadio.ts` / `PfGMRadio.prefab`。只画圆点，不含字。
   - 从 `gmajor/index.ts` 导出这两个类。
   - 理由：和勾选框成对，但勾选可以多选，单选必须有人管「只能一个」。组负责互斥，圆点负责画。

3. **一项是一行，圆点在行里**。
   - 组只看自己的直接子节点。每个直接子节点里正好一颗 `PfGMRadio`。子节点顺序就是 `index`（第一个是 0）。
   - 圆点不要直接挂在组下面。挂在组下面时，父节点是组，热区会变成整组。
   - 没有圆点、或一行里多于一颗：`console.error`，这一项不进入 `index`，后面的序号前移。
   - 组不摆位置、不改行的宽高。行的坐标和 `contentSize` 由调用方定。

4. **热区是被绑节点的矩形**。
   - 圆点的父节点（这一行）是默认热区。组收集时，这一项还没绑过，就 `bind` 这一行。
   - 调用方要换成别的节点，对这一项再 `bind(node)` 一次，换掉上一个。
   - 热区就是这个节点的 `UITransform` 宽高和锚点。不另画热区，不按文字像素收边。
   - 字是行里的子节点，自己不要 `addClick`。子节点上再注册点击，会把事件吃掉，行收不到。
   - 组在热区上 `gu.addClick(node, ..., { press: 'none' })`。按下不缩放、不压暗。圆点自己不注册点击，不挂 `Button`。
   - 收集之后再 `bind`：卸掉旧节点上的点击，改挂到新节点，回调仍是选中这一项。

5. **值是 `index`**。
   - `-1` 表示还没有选中。属性默认 `-1`，和检查器同一份。
   - `setIndex(index)` 只改选中，不调用 `onChange`。越界收成 `-1`。设成当前值也不回调。
   - `setOnChange(cb)` 只在用户点到另一项、并且值真的变了时调用，参数是新的 `index`。
   - 点已经选中的那项：不取消，不回调。
   - 不用字符串 id，不用布尔数组。圆点没有自己的业务布尔；组叫它 `setOn(true/false)` 只改圆点显隐。

6. **形态和尺寸**。
   - 未选是空心圆。选中时空心圆还在，中间叠实心圆点。不打勾。
   - 边长一档 48，和勾选框一样。源图 96，显示 48。不做 72，不做两档。
   - 子节点固定 `ring`、`mark`。`ring` 贴 `radio`，`mark` 贴 `radio_mark`。未选时 `mark` 隐藏。两张都是 `SIMPLE`，不切九宫格。
   - 取图只用 `applySkin`。不要 import 游戏 `SkinKit`。

7. **不加 `update()`**。
   - `PfGMRadio` 和 `PfGMRadioGroup` 都不写 `update`，也不为检查器改值做轮询。
   - `onInit` 按当时的 `index` 排一次，并贴皮。
   - 检查器里随后再改 `index`，不会当场换圆点。要看新的选中态，走 `setIndex` 或重新加载组件。
   - 可以 `@executeInEditMode(true)`，只为了编辑器里跑一次 `onInit`。这不是 `update`。

8. **皮两张**。`count_plate` 不动，已画槽的坐标和画法不动。

   | 槽名 | 源图 | 显示 | sliced | 画法 |
   |---|---|---|---|---|
   | `radio` | 96×96，仍从 `[560, 1394]` 起（原来是 144 的预留，缩小，不挪） | 48×48 | false | 空心圆。描边和勾选框同一套：深橄榄绿 3、浅橡木、奶油。画成圆，不要方框 |
   | `radio_mark` | 96×96，新槽 | 48×48 | false | 实心圆点，草地绿，和勾同一套绿。叠在圆心 |

   - `radio_mark` 的坐标实现时再排：2048 的图上找一块 96×96，和现有槽间距大于 24，不占用、不挪动 `count_plate` 和已画槽。
   - 画图脚本现在的断言是实画 34、预留 2。画完这两张后改成实画 36、预留 1（只剩 `count_plate`）。
   - 跑 `tools/draw-zoo-v7-ctrl.mjs` 会按脚本现有逻辑覆盖 `style/ZooV7/控件/history/v8/`。
   - 不跑 `tools/export-zoo-v7-plist.mjs`。

9. **演示在 `LyControls`「选择」页，一条横排**。竖排三条在这一页放不下：页高 957，内容从 y=447 排到 y=−458，最大空档只有 66 像素（向上弹出的下拉底边 −376，到底部说明字顶边 −442）。
   - 组节点 `ctlRadio`，放在 `(0, −409)`。三行是它的直接子节点，中心 x 为 −160、0、160，y 为 0。
   - 每行热区 140×48。左边缘 −230，右边缘 230，落在内沿 ±276 里面（左右各余 46）。行的上下是 −433 到 −385，和上边的下拉、下边的说明字各约 9 像素。
   - 文案「低 / 中 / 高」，圆点在行的左侧，字在圆点右边。字是行的子节点，不单独注册点击。
   - 默认 `index` 为 1（「中」）。打开时不改 `pickNote` 的原句。点某一项之后写成 `单选 → 低` / `中` / `高`。
   - 不加标题行。不放「更多」页。不动这一页已有控件的 y。向上弹出的下拉仍在 y=−340，它往上展开，不会盖住这一行。

10. **收集时机**。组在 `onInit` 收集一次。圆钮的 `onInit` 只贴图，并按已经 `setOn` 过的结果显示 `mark`，不要无条件把点关掉。这样组先跑或圆钮先跑，选中态都还在。不监听子节点后来的增删；运行中新加的行这次不收。

## 不做什么

- 两个类都不写 `update()`。
- 不做 `count_plate`，不做红点，不做多语言。
- 不改 `LySetting`。
- 不把 demo 放进「更多」页，也不在「选择」页做竖排三条。
- 组不负责排版，不提供字符串 id。
- 点已选项不能取消。
- 不改版本号：不动 `CHANGELOG.md`、`gmajor/launch/GMLauncher.ts`、`extensions/gmajor/package.json`、`assets/game/config.ts`。
- 不改 `.cursor/rules/`、不改 `docs/临时总结/`、不改 `docs/界面组件/进度.md`。
- 不跑 `tools/export-zoo-v7-plist.mjs`。
- 不动 `FFrame-zoo`。
- 不 commit、不 push。

## 验收标准

1. 「选择」页在向上弹出的下拉和底部说明字之间，有一行三个单选：低、中、高。打开时「中」是选中的，说明字仍是原来的提示句。
2. 点圆点或点右边的字，都变成选中这一项，另外两项的圆点消失。说明字变成 `单选 → 低` / `中` / `高`。
3. 再点已经选中的那一项，选中不变，说明字不再写一次。
4. `setIndex` 能改选中，且不触发 `setOnChange`。`index` 为 `-1` 时三颗都没有圆点。
5. 三行的左右边缘在 ±276 内，没有压到背景边框，也没有盖住下拉或说明字。
6. 按下这一行时，行不缩小、不变暗。
7. 皮是空心木圆加草地绿圆点，不是方框，也不是勾。
8. 图集实画 36、预留 1。`count_plate` 仍是预留。已画槽的坐标没变。
9. 已有控件的表现不变。「选择」页原有节点的 y 不变。

## 实现时要守的坑

1. 控件不许压背景边框。这一页内沿是 ±276。左边 = x − 宽/2，右边 = x + 宽/2。并排若改成纵向，x 和宽一起改。
2. 代码里新建的节点必须 `node.layer = 父节点.layer`，子节点也要跟。
3. `LyControls.prefab` 里新嵌的组、圆点都要登记 `nestedPrefabInstanceRoots`。漏了会退化成空节点。嵌套实例的坐标以 `PrefabInstance.propertyOverrides` 里的 `_lpos` 为准，只改节点上的 `_lpos` 运行时不生效。
4. 取图只用 `applySkin`，不要 import 游戏 `SkinKit`。
5. 不跑 `tools/export-zoo-v7-plist.mjs`。
6. 画图会改断言：实画 34、预留 2 → 实画 36、预留 1。`radio` 从预留变成实画，并多一张 `radio_mark`。
