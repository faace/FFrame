# 控件展示窗 共识

## 目标

在设置弹窗之外新开一扇控件展示窗，把已完成的控件按「按钮 / 选择 / 展示」三页平铺展示，每个控件在窗口上标出中文名和类名。设置页保持原样不动。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后 `/implement` → `/review`。

2. **名字**：`LyControls`。脚本 `LyControls.ts`、预制体 `LyControls.prefab`，都落在 `assets/game/bundles/Demo/DemoHome/`。
   - 理由：语义是「控件总览」，和已有的 `LyButtons` 并列不撞。不用 `LyWidgets`（说明.md 明确不独立 Widget 库）、不用 `LyGallery` / `LyShowcase`（看不出内容）、不用 `LyControlPanel`（读成设置）。

3. **首页入口：复用 `btnDiamond`，改名 `btnControls`，文案「控件展示」，位置 y=-260 不动，主题仍是 `info`（theme 4），版式纯文字（style 1）。**
   - 理由：它现在只弹一句「用钻石买下这一格」，是四颗里演示价值最低的；确认框的弹法在 `LyButtons` 已演全，删掉不丢演示。它是纯文字钮，改文案不会和图标错位。
   - 改的是 `ScDemoHome.scene` 里该实例的三处覆盖值（`_name`、`_string`、`text`）+ `ScDemoHome.ts` 里的 `getChildByName` 名和点击目标。不新增第 5 颗，不动其它三颗。

4. **基类与尺寸**：`LyControls extends GMFrame`，`width = 640`、`height = 1120`，标题「控件展示」，关闭钮默认开，底框默认开。
   - body 实际 592 宽 × 约 1022 高（骨架算出来的）。
   - 理由：640 与 `LyButtons` 一致、距屏边各 40；1120 让 body 够放三页内容。不照抄设置页 600×760，也不用默认 620×800（body 只有 752，塞不下）。

5. **页签作容器，三页**：

   | 页 | 放什么 |
   |---|---|
   | 按钮 | `PfGMBtn` 八颗（见第 6 条） |
   | 选择 | 滑条 `PfGMSlider`、步进 `PfGMStepper`、开关 `PfGMSwitch`、勾选 `PfGMCheck` |
   | 展示 | 进度条 `PfGMBar`、道具格 `PfGMItemCell` 四格 |

   - 分法按「用户能不能改值」：能改值的进「选择」，只显示的进「展示」。
   - 页签 3 颗是硬上限：`PfGMTabs` 每颗固定 154 宽（26 号字 × 五个中文字），相邻叠 3，第一颗让过 20 圆角；4 颗要 628，超 body 的 592。
   - 以后补控件（下拉框、输入框进「选择」，红点、Toast 进「展示」），页数满了再议。

6. **按钮页八颗中档、两列四行**：

   | 行 | 左 | 右 |
   |---|---|---|
   | 1 | `primary` | `secondary` |
   | 2 | `warning` | `neutral` |
   | 3 | `info` | `禁用` |
   | 4 | 纯图标 `icon_close` | 图标加字 `icon_plus`「图标加字」 |

   - 按钮自己的字就是主题名，不另挂 label。字用英文（`primary` 等）因为直接对上 `ctrl.plist` 的子图名。
   - 纯图标那颗没有文字位置（`style = icon` 时控件自己藏 label），单独在它下面挂一行 16 号浅灰小字「icon_close / 纯图标」。
   - 中档 260×88 两列 260+32+260 = 552，body 592 装得下；大档 380 单列五颗要 600 高，太费，且首页已能看到大档。
   - 禁用那颗照样 `gu.addClick`，回调里 `console.error('[LyControls] 禁用钮不应进回调')`，用来证明禁用确实拦住了点击（与 `LyButtons` 同一套写法）。

7. **选择页四行**：

   | 行 | 控件 | 初始值 / 交互 |
   |---|---|---|
   | 1 | `PfGMSlider` | `setValue(0.6)`，宽 280；拖动自带，填充跟着动 |
   | 2 | `PfGMStepper` | 缺省 `value 3 / min 0 / max 10 / step 1`；点加减调 `setValue`，到边界由控件自己禁用 |
   | 3 | `PfGMSwitch` | 初始关；点一下 `setValue(!value)` |
   | 4 | `PfGMCheck` | 初始未勾；点一下 `setValue(!value)` |

   - 滑条只放一条（不照设置页摆音乐/音效两条）：要验的是轨道、填充、滑块三者联动，一条就够，两条只重复 label。

8. **展示页两行**：

   | 行 | 控件 | 初始值 / 交互 |
   |---|---|---|
   | 1 | `PfGMBar` 320 宽 + 加/减两颗小档钮 | 默认 `PfGMBarText.percent`；加减各 0.25，夹在 0–1 |
   | 2 | `PfGMItemCell` 四格（4×96 + 3×4 = 396） | 星星 999 / 金币 12 / 钻石 3 / 宝箱 1000；四格都可点，点一下切换自己的选中框 |

   - 进度条不放「切换文字模式」那颗钮：三颗小档位（320+3×64+缝）超出控件区宽度，且条上有字的默认形态已由 `percent` 体现。
   - 道具格四格都可点，直接对上验收第 7 条；`PfGMItemCell.selected` 与 `setSelected(on)` 都是公开面，不用改框架。

9. **每个控件的 label：中文名 22 号深墨 + 类名 16 号浅灰，两行，右对齐收口在控件左侧。**
   - label 区宽 150，右边缘在 x=-186；控件区中心 x=60。
   - 适配核过：滑条 280 ✓、步进 348 ✓、进度条 320 ✓、开关 96 ✓、勾选 48 ✓、道具格四格 396 ✓。
   - 按钮页例外（见第 6 条），不挂控件级 label。
   - 字用 `db://gmajor/fonts/main.ttf`（`assetManager.assets.get`，与 `PfGMTabPageDemo` 同一套取法），不用系统字。

10. **预制体里嵌控件实例（编辑器可见），页面节点也在预制体里；label 和页面收编由脚本做。**
    - `LyControls.prefab` 结构：根（脚本 + `UITransform`）→ `panel` → 一个 `PfGMTabs` 嵌套实例 + 三个页面节点（`pageBtn` / `pagePick` / `pageShow`，各挂 `PfControlPage`），页面与页签实例同级平铺。页面里的控件是各自预制体的嵌套实例。
    - 运行时脚本把三个页面 `tabs.insert(node, '按钮' / '选择' / '展示')` 收进页签内部；`adopt()` 会把节点移进页签的 `panel` 并统一尺寸、只显示当前页，是 `LyTabs` 已在用的既有行为。
    - label 不写进预制体，由脚本按控件节点的实际 y 生成、对齐到左侧：坐标只有一处来源（预制体里的实例位置），补新控件时只需要在脚本的表里加一行「节点名 → 中文名 / 类名」。
    - **风险点（实现时必须处理）**：`LyControls.prefab` 根上 `cc.PrefabInfo` 的 `nestedPrefabInstanceRoots` 必须登记全部嵌套实例根（页签 1 个 + 各页控件约 19 个）。漏登记会退化成空节点（就是上次开关那个坑）。写完用脚本校验：数组里的 id 与所有带 `cc.PrefabInstance` 的节点一一对应，缺一即报错。

11. **`PfControlPage.ts` 新建**，`extends GMTabPage`，空实现（继承默认的立刻 `done`）。
    - 不复用 `PfGMTabPageDemo`：它会自建「点上面的页签切换」说明字，记录页还 `scheduleOnce` 等两秒，会干扰本窗验收。
    - 三个页面节点在预制体里就挂好这个名字，`insert` 时 `claim()` 认的是 `GMTabPage` 组件，所以直接 `addComponent` 也成立；单独建文件是为了预制体里看得出「这是页」。

12. **皮的加载**：`onLayerInit` 里照 `LySetting` 的做法调一次 `SkinKit.loadSkin`，控件自己的 `applySkin` 取槽。不新增皮肤槽、不动图集。

13. **设置页不动**：`LySetting.ts` / `LySetting.prefab` 这次一个字不改，仍是已验证的状态。拆设置页是另一件事。

## 不做什么

- 不改 `LySetting`（脚本和预制体都不碰），不把设置页控件搬走。
- 不动 `gmajor/`：控件脚本、预制体、皮肤槽、`gm.version` 都不改。`PfGMItemCell.selected` 等公开面这次够用。
- 不实现预留的 8 个槽（`radio` / `input` / `badge` / `dropdown` / `toast` / `count_plate` / `scrollbar` / `scrollbar_thumb`），下拉框仍留到下一步。
- 不新增第 5 颗首页按钮，不动 `btnStart` / `btnAd` / `btnGold`。
- 不改 `docs/界面组件/进度.md`、`docs/界面组件/说明.md`、`01-naming.mdc`（含已知的滑条描述过时、勾选框已点过等旧说法）。
- 不动 `FFrame-zoo`、不碰 `ctrl.plist.meta`、不跑 `FFrame-asset-line/tools/export-zoo-v7-plist.mjs`。
- 不 commit、不 push。

## 验收标准

1. 首页点「控件展示」进新窗，标题「控件展示」，关闭钮能关。
2. 三个页签都在（按钮 / 选择 / 展示），能来回切换，切页不卡（页签自带的 loading 会短暂出现属正常）。
3. 按钮页八颗：五主题底色各不相同、`禁用` 那颗是去色态、纯图标那颗只有图标、图标加字那颗两者都在。点禁用那颗不进 alert，控制台出现 `禁用钮不应进回调`。
4. 选择页：滑条能拖、填充跟着滑块动；步进 +/− 改数字、到 0 和 10 时对应钮禁用；开关关→开→关；勾选框能勾上、能取消。
5. 展示页：进度条默认显示百分比，点加/减填充跟着动；道具格四格各自点一下选中框出现、再点消失。
6. 每个控件左侧有「中文名 + 类名」两行字，字不压到控件、不叠行。
7. 不挤压、不重叠、不出面板；三页内容都不贴页签板边。
8. `LyControls.prefab` 在编辑器里打开能看到页签实例和各页控件（label 不出现属正常，label 是运行时生成的）。
