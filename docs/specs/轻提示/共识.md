# 轻提示 共识

## 目标

把轻提示的总控从 `PfGMToast` 挪到和 `gu.alert`、`gu.showLayer` 一样的门面上。游戏里写 `gu.toast('棋盘已满')`。控件只画一条。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后 `/implement` → `/review`。

2. **三层**。
   - `GMUIManager` 只留薄入口：`toast(text)`、`toastHide()`、`setToastAnchor(anchor)`，转给 Host。
   - `GMToastHost` 挂在 Overlay 的 `toasts` 节点上，管队列、锚点、条数、时长、让位、预制体只加载一次、定时器。
   - `PfGMToast` 只画一条：`bg` / `label`、字号颜色、`setText`、自己的淡入淡出。不认识兄弟，不改别人的坐标，不 `load` 预制体，不 import `gu`。
   - 理由：队列放在控件文件的模块变量里时，一条控件既画自己又当整列的总管。独立 Host 避开把排版塞进已经很长的 `GMUIManager`，调用面仍和 `gu.alert` 并列。
   - 环这样解开：`PfGMToast` 不再 import `gu`。`GMToastHost` 可以 import 控件。`GMUIManager` 只碰 Host。

3. **对外三个方法，旧静态入口删掉**。
   - `gu.toast(text: string)`：弹一句。空串 warn 后忽略。
   - `gu.toastHide()`：正在显示的全部收起。
   - `gu.setToastAnchor('top' | 'center' | 'bottom')`：改停靠。
   - 删掉 `PfGMToast.show` / `hide` / `setAnchor`。演示页改成调 `gu`。
   - `gu.toastRoot()` 一并从公开面拿掉。容器只给 Host 用。确认框也没有对外的 `alertsRoot()`。
   - `GMToastAnchor` 仍从 `gmajor/index` 导出，类型跟着 Host 走，不再从控件文件导出。
   - `PfGMToast` 类本身仍导出（它还是框架控件），注释不再写 `show`。

4. **锚点可以随时改。开机默认 `center`。**
   - 传入的值和当前不同：先 `toastHide()`，再改停靠点。已经在淡出的条立刻离开队列，停在原处淡完，不跟着新锚点挪。
   - 传入的值和当前相同：不收起，不 warn。
   - `gu.toast(text)` 不收坐标，也不收单条锚点。

5. **一列的顺序**。
   - 最老的贴着停靠点，新的排在这一列的最外一格。
   - 贴着停靠点的那条消失后，其余的补向停靠点。每条自己计时，别人消失或让位都不重置剩余时间。
   - 同时最多 3 条。第 4 条进来时挤掉最老的那条（不等它自然到点）。这个 3 只写在 Host 的一处常量里。这次不加 `setToastMax` 之类的运行时接口；以后改成 2、4、5 改这个常量。
   - 同一句不续命。再调一次就再出一条，各自计时。

6. **三档停靠**。屏高用 `toasts` 容器的高度现算。条高 72，间距 12，一格 84。边距 120。
   - `top`：最高点钉在离屏幕顶 120（格子中心再减 36）。新的一条从自己格子下方 40 像素挪上来。上面消失后往上补，最高点不动。
   - `bottom`：最低点钉在离屏幕底 120（格子中心再加 36）。最老的贴着最低点，新的排在上面，从自己格子上方 40 像素挪下来。最低那条消失后，上面的往下补，最低点不动。
   - `center`：最高点钉在屏幕中线上方 168。新的一条从中线（y = 0）向上飘到最下面那一格。只有一条时，从中线飘到 y = 168。满 3 条时，最下面一条在中线（y = 0）。上面消失后往上补，最高点不动。
   - 让位 0.15 秒，新条入位 0.2 秒，都用现有的缓动。淡入 0.15 秒、淡出 0.2 秒，只动透明度。

7. **停留时长不动**。2.0 秒起，超过 12 字每字加 0.05 秒，封顶 3.5 秒。

8. **外观不动**。480×72，单行，`SHRINK`，28 号深墨 `92,64,32`，不描边，皮 `toast`。预制体仍是根 + `bg` + `label`。不重画。

9. **不挡输入，不可点，不进弹层栈**。容器不挂 `BlockInputEvents`。点条本身没有反应。`closeAll()` 和切场景都不带走它。

10. **切场景不清**。挂在常驻 Overlay 上，等自己消失。要立刻清时调用方调 `gu.toastHide()`。

11. **预制体仍由 Host 在第一次 `gu.toast` 时从已加载的 `GMUI` 包加载并缓存**。不进 `config.boot`，也不要游戏 `setToastPrefab`。确认框的皮是游戏的 `LyAlert`，轻提示的皮是框架预制体。

12. **定时器仍用 Overlay 上 `GMOverlayHost` 的具名调度**。每条一个名字，销毁前取消。重排不取消别人的计时。

13. **去掉 `PfGMToast.update()`**。运行时改字只走 `setText`。检查器里的 `text` 在 `onInit` 排一次。

14. **破坏性变更，框架版本 `0.9.0` → `0.10.0`**。
   - 改 `gmajor/launch/GMLauncher.ts` 的 `version`、`extensions/gmajor/package.json` 的 `version`、仓库根 `CHANGELOG.md`。
   - 本仓库演示工程 `assets/game/config.ts` 的 `version.gmajor` 改成 `0.10.0`。
   - 改法写进 CHANGELOG：`PfGMToast.show` → `gu.toast`，`hide` → `gu.toastHide`，`setAnchor` → `gu.setToastAnchor`；不再使用 `gu.toastRoot()`；锚点可随时改，默认 `center`。

## 不做什么

- 不做「同一句只续命、不新增」。
- 不做「锚点只能定一次」。
- 不做「新的一条插进最上面」。
- 不在切场景时自动 `toastHide()`。
- 不做点击关闭，不做奖励飘字。
- 不加运行时修改最大条数的接口。
- 不改预制体节点、不改图、不改图集、不改字号和时长公式。
- 不改 `FFrame-zoo`。动物园的 `config.version.gmajor` 本来就停在 `0.6.3`，这次不动。
- 不改 `docs/临时总结/`。
- 这次不改 `.cursor/rules/`。规则条文等单独确认后再并。
- 不 commit、不 push。

## 验收标准

1. `gu.toast('棋盘已满')` 能弹出一条，到时自己消失。空串不弹出。
2. 开机不调用 `setToastAnchor` 时，一条提示从屏幕中线飘到中线上方 168。连弹三条时，最老的在最高点，最新的在中线；最上面消失后，下面的往上补，且没被补的那条剩余时间不变。
3. 同一句连调三次得到三条，各自计时。
4. 第 4 条出现时，最老的那条立刻开始收起，屏幕上仍只有 3 条。
5. `gu.setToastAnchor('top')` 先收起当前的，之后新的一条最高点在离顶 120，新的在下面。再设一次 `'top'` 不会把正在显示的收掉。`bottom` 的最低点在离底 120，新的在上面，消失后往下补。
6. 提示在的时候，点它后面的按钮能点到。点提示本身没有反应。
7. 弹 Toast 时打开一个弹窗再关掉，Toast 还在。切场景不主动清掉它。
8. 演示页三颗按钮改走 `gu.toast`，说明文案按默认 `center` 来写。
9. 工程里不再有 `PfGMToast.show` / `hide` / `setAnchor`，也不再有公开的 `gu.toastRoot()`。
