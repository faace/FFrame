# 页签 共识

## 目标

`PfGMTabs` 的页签宽度改成可设的字数，整排一样宽。页签条左边留半个圆角直径，右边留一个直径。一排超出这块可排区域时，只横滑页签条。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后实现。

2. **整排共用一个宽度**，不给每一页各设一个。宽度用字数定，写在 `PfGMTabs` 上。
   - 字段 `chars`，方法 `setChars`。和 `index` / `setIndex` 同一份。
   - 默认 `5`。不改这个数，每颗仍是现在五个字的宽度。
   - 填 `2`，每颗按两个「中」来量；填 `4` 就按四个「中」。左右留白仍是现在的各 12，不算进字数。
   - 必须是大于 1 的整数，最少 2。`1`、`0`、负数、小数打错误日志，属性回到上一次合法的字数，宽度不变。
   - 某一页的标题比这个字数更长：这一颗的宽度不变，字缩小放进去。

3. **页签条左边留半个圆角直径，右边留一个直径**。板子 `panel` 显示尺寸半径 20，直径 40。左边留 20，右边留 40。可排宽度 = 控件宽 − 60。
   - 理由：右边要让开圆角。左边按整直径留太宽，收掉半个直径。
   - 页签从左留白之后往右排，不拉宽去填满。右边没排到的地方空着，但空着的部分也不能进入右边那 40。

4. **一排超出可排宽度时横滑**。页签条裁在这块留白以内，超出的裁掉。
   - 只按上面的页签左右拖。下面板子里的内容不左右滑，也不靠滑动换页。
   - 一排没超出时拖不动，停在最左边。
   - 换到某一颗时，只把那一整颗滚进可排区域。已经完全露在里面的，不再为它滚动。
   - 不画滚动条。

5. **整颗控件最窄 360**。板子和上面那排一样宽，都跟根节点。设得更窄就拉回 360，并打一条警告。
   - 360 时，扣掉左 20、右 40，可排宽度是 300。默认五个字的页签大约 154 宽，一颗放得下，两颗会稍微超出，可以横滑。

6. **不改这些**：页签高仍是 64。皮仍是 `tab_normal`、`tab_selected`、`panel`。子节点仍是 `tabs`、`panel`。内容仍是 `GMTabPage`。`onShow` / `onHide` 仍要调用 `done`。点击仍是 `gu.addClick`。

7. **版本**：只加可选字段 `chars`，默认 5，行为兼容「不填就是五个字」。升修，并在 `CHANGELOG.md` 写一句。左边留白后来从 40 收到 20，记在 0.10.2。

## 不做什么

- 不给每一页单独设宽，也不提供直接填像素的宽度接口。
- 不把页签压窄来塞进板子，不把多出来的收进「更多」。
- 不让板子里的内容左右滑来换页。
- 不改页签高度、皮、页面切换流程。
- 不改已经套了这个控件的业务页面。字数保持默认 5 时，单颗宽度不变；只有左右留白和超出后的横滑会影响到旧页面。

## 验收标准

- [ ] `chars` 默认 5。设成 2、4 时，每一颗都按对应字数一样宽，标题更长的字缩小。
- [ ] `chars` 设成 1、0、负数或小数时，打错误日志，字数和宽度保持上一次合法值。
- [ ] 根节点宽小于 360 时拉回 360，并打警告。
- [ ] 页签条左边空出 20、右边空出 40。右边不压板子顶上的圆角。
- [ ] 一排超出可排宽度时，只能拖页签条横滑；板子里的内容不能靠左右滑换页。没超出时拖不动。
- [ ] 换到已经完全可见的那颗时，页签条不滚动；换到被裁掉的那颗时，把它整颗滚进可排区域。
- [ ] 不设 `chars` 的旧用法，单颗仍是五个字宽，页面切换和点击跟现在一样。
