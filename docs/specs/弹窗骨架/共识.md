# 弹窗骨架 共识

## 目标

普通弹窗共用框架里的一套骨架：标题、关闭、左上角、底框和尺寸都由它摆。标题上的两颗铆钉压在面板顶边的棕色框线上。确认框只把标题和关闭钮挪到同一条线上。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后 `/implement` → `/review`。
   - 理由：一块功能，接法已经问完。

2. **放在框架**。新增纯基类 `GMFrame`（继承 `GMLayer`，没有预制体）。`ZooLayer` 和 Demo 的 `LyTabs` 改继承它。`GMAlert` 不继承它。
   - 理由：普通弹窗现在各写一套顶栏。确认框不读这套参数，所以不能做进所有 `GMLayer`。

3. **子类在自己的脚本里设参数**。打开弹窗的调用不带这些参数。只写和默认不同的项。
   - 默认：宽 620、高 800、有标题、有关闭、有底框、没有左上角。
   - 标题文字用 `setTitle`。不要标题时显式关掉，不是靠不调用 `setTitle`。
   - 不要关闭时显式关掉。关闭钮默认点了就关自己。
   - 不要底框时显式关掉。关掉的是 `panel` 上的木框，遮罩还在。
   - 左上角传入回调才创建。图标不传则用 `icon_help`，要换再传图标。
   - 理由：没回调的按钮点了没有去处。关闭钮自己有动作，所以默认就在。

4. **铆钉压在棕色框线上**。标题条整体上移，直到两颗铆钉落在面板顶边那条棕色框上。关闭钮和左上角钮的垂直中心与标题同一高度，也在这条线上。左上角与关闭钮左右对称，规格与关闭钮相同（中档纯图标、次按钮底）。
   - 理由：现在标题中心在顶边往下 15，铆钉落在棕色边的下面。

5. **没有标题时，按钮位置不变**。关闭钮和左上角仍贴着这条棕色边。内容区不给标题留空，从这条边下面开始。有标题时，内容仍放在标题条下沿和面板底边之间。

6. **关掉底框时，位置算法不变**。不画 `panel` 那张图。标题和按钮仍按木框在时的那条边来摆。遮罩照旧。
   - 底框由骨架负责。预制体里 `panel` 上已有的 Sprite 由骨架复用，不另画一张。

7. **尺寸以骨架字段为准**，搭好后写到 `panel` 的 `UITransform`。`LyTabs` 继续写 640×480。动物园弹窗用默认 620×800，不再在 `ZooLayer` 里另存一份宽高。

8. **确认框其余不动**。只把标题和关闭钮挪到同一条棕色边上，关闭钮仍与标题垂直居中。正文、确定/取消、`showTitle` / `showClose`、尺寸都不走 `GMFrame`。

9. **内容挂 `body`**。骨架创建 `body`。`LyTabs` 的页签放进 `body`。动物园各弹窗仍只在 `onLayerInit` 里 `setTitle`，不再自己建顶栏。

## 不做什么

- 不改确认框的文案、按钮数量、显隐参数和尺寸。
- 不给确认框加左上角，也不让它开关底框。
- 不迁移 Demo 里页签、确认框以外的旧弹窗。
- 不改遮罩和进出场动画。
- 不改 `PfGMTitle`、`PfGMBtn` 的控件行为，只改它们在弹窗上的位置和显隐。
- 不在 `showLayer` 的参数里加这套开关。
- 不改 `.cursor/rules/`，规则要等单独确认。

## 验收标准

- [ ] 页签窗的两颗铆钉压在面板棕色顶边上，关闭钮与标题垂直居中，尺寸仍是 640×480。
- [ ] 关掉标题后，标题条不在，关闭钮位置不变，内容从棕色边下面开始。
- [ ] 关掉关闭后，右上角没有钮。
- [ ] 关掉底框后，木框不在，遮罩还在，标题和按钮位置不变。
- [ ] 左上角没传回调不出现；传了回调才出现，默认是 `icon_help`。
- [ ] 动物园弹窗默认 620×800，有标题、有关闭、有底框，没有左上角。
- [ ] 确认框的标题和关闭钮与普通弹窗同一条线，点关闭仍等于取消，其余行为不变。
- [ ] 打开弹窗的调用处不用加新参数。
