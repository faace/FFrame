# 下拉框 共识

## 目标

在框架里补第 10 个控件：下拉框 `PfGMSelect`，配一个可复用的行控件 `PfGMOption`。收起态是一个盒子显示当前项，点开弹出选项列表，点一项回填并收起，点外面只收起不改值。文字项和带图标项用同一套类。

## 已定决策

1. **路径**：中。grilling → 本文件 → 确认后实现 → 验收。

2. **命名跟 HTML 对齐**：
   - 容器 `PfGMSelect` / `PfGMSelect.ts` / `PfGMSelect.prefab`（对应 `<select>`）。
   - 行 `PfGMOption` / `PfGMOption.ts` / `PfGMOption.prefab`（对应 `<option>`）。
   - 理由：`PfGMSelect` 是容器、`PfGMOption` 是行，和 HTML 的父子关系一一对上；以后带图、带副标题的项只改 `PfGMOption`，不动 select。

3. **`PfGMOption` 是独立控件基类**，从 `gmajor/index.ts` 导出。
   - 继承 `GMComponent`，`@executeInEditMode(true)`。
   - 子节点固定 `bg`、`icon`、`label`，根上必须有 `UITransform`（未选中时没有底板，命中仍靠它）。
   - 尺寸：宽 = 父给（列表宽），高固定 64。
   - 属性：`text`（字符串）、`icon`（物品槽名，例如 `icon_star`）、`selected`（布尔）。
   - 方法：`setText` / `setIcon` / `setSelected`，都和属性同一份。
   - `icon` 为空字符串时把 `icon` 节点藏起来，字从左边 20 起；有图标时图标 36 见方，字跟在后面。和收起态同一套对齐规则。
   - 皮：选中行底板 `dropdown_item_on`（草地绿板，白字描边 3）；未选中行**不画底板**，只有深墨字。`bg` 子节点在未选中时 `active = false`。
   - 点击由外层用 `gu.addClick` 注册，控件不挂 `Button`。

4. **选项数据类 `GMOptionItem`**，和 `GMTabSlot` 同一套写法：

   ```ts
   @ccclass('GMOptionItem')
   export class GMOptionItem {
       @property text = '';
       @property icon = ''; // 物品槽名，例如 icon_star。空着只显示文字
   }
   ```

   `PfGMSelect` 的属性是 `@property({ type: [GMOptionItem] }) items`。纯文字下拉就是 `icon` 全空，带图标下拉就是全填，**同一个类，不写两套**。

5. **图集：实画 25 → 31，预留 8 → 5。**

   | 槽名 | rect（源图像素） | border（源图 L/R/T/B） | sliced | display |
   |---|---|---|---|---|
   | `dropdown` | `[32, 1570, 640, 144]` | `[32, 32, 30, 32]` | true | 320×72 |
   | `dropdown_list` | `[1320, 912, 640, 128]` | `[32, 32, 36, 34]` | true | 320×64 |
   | `dropdown_item_on` | `[256, 1856, 640, 128]` | `[32, 32, 32, 32]` | true | 320×64 |
   | `icon_arrow` | `[1496, 32, 88, 88]` | `[0, 0, 0, 0]` | false | 44×44 |
   | `scrollbar` | `[1656, 32, 32, 320]` | `[16, 16, 24, 24]` | true | **16×160** |
   | `scrollbar_thumb` | `[1656, 384, 32, 80]` | `[0, 0, 24, 24]` | true | **16×40** |

   - 已画的 25 个槽的 `piece()` 坐标和画法**一个都不动**。
   - `scrollbar` / `scrollbar_thumb` 最初按 32 宽画，实际显示太粗；改成 16 宽重画（细描边 2、圆角取半宽），不用 scale 缩放——缩放会把高度一起缩掉。

6. **三个新槽的画法**，全用现有 `piece()` 函数、2 倍源图、最近邻放大：
   - `dropdown`：和 `panel` 同一套 `frame()` —— 深橄榄绿描边 3 + 浅橡木 7 + `CREAM_DK` 2 + 奶油，圆角 12。
   - `dropdown_list`：上边直角（贴住盒子不露圆角）、下边圆角 12。
   - `dropdown_item_on`：`plate(320, 64, 10, 3, OLIVE, GREEN, ...)`，草地绿板。
   - `icon_arrow`：`paintGlyph` 画下尖圆角折线（∨）。
   - `scrollbar`：`frame(16, 160, 8, [[2, OLIVE], [4, OAK], [1, CREAM_DK], [99, CREAM]])`。
   - `scrollbar_thumb`：`plate(16, 40, 8, 2, OLIVE, OAK, null, OAK_DK, false)`，窄条不加顶部高光带。

7. **收起态尺寸**：根宽读节点宽度（默认 320，最小 200），**高固定 72**。子节点固定 `bg`、`icon`、`label`、`arrow`，都在预制体里。
   - 当前项有图标就一起显示，图标 36 见方。
   - 文字字号 26、深墨 `92,64,32`、不描边、左对齐；无图标左内边 24，有图标从 72 起。
   - 箭头贴右侧，中心距右内边 24，44 见方。`index = -1` 表示无选中。

8. **展开列表用引擎自带的 `ScrollView`，骨架放进预制体。**
   - 预制体结构：根 → `bg` / `icon` / `label` / `arrow` / `list`，`list` 下面是 `view`（Mask）→ `content`，以及 `scrollBar`（ScrollBar 组件）→ `bar`（handle）。
   - 运行时 `instantiate` 克隆 `list`，只往 `content` 里塞行；滚动由 `ScrollView` 处理，不做手写滚动、不做行复用。
   - `list` 在预制体里默认 `active = true`（所见即所得），非编辑态由 `hideTemplate()` 收起模板。
   - `dressSkeleton()` 在 `onInit` 里给 `list` / `scrollBar` / `bar` 贴皮，编辑器里就能看到真实皮肤，不用等展开。
   - 每个运行时节点都 `node.layer = 父节点.layer`（滑条 `fillClip` 那条坑）。

9. **行高与滚动**：行高 64；列表宽 = 根宽；上下各内衬 6；**一屏最多 8 行**，再多交给 `ScrollView` 滚。
   - 选中行：绿板 + 白字描边 3。未选中行：无底板，深墨字。
   - 滚动条平时透明，滚动时出现，停手 0.8 秒渐隐（`ScrollBar.enableAutoHide = true`、`autoHideTime = 0.8`）。
   - 内容放得下时（项数不超过一屏）整条滚动条隐藏。

10. **点外面关闭：透明遮罩 + `BlockInputEvents`，不压暗。**
    - 展开时在控件父节点下建遮罩，尺寸取父节点 `contentSize`，`gu.addClick(mask, close, { press: 'none' })`。
    - 遮罩只铺到控件所在页面，点标题栏、页签条不触发收起。
    - 页面被切走（`onDisable`）也收起。

11. **向上弹还是向下弹**：
    - 列表高 = 展示行数 × 64 + 12（上下内衬各 6）。
    - 边界取**控件所在页面节点的矩形**。
    - 下方放得下 → 向下；下方放不下且下方仍比上方大 → 继续向下；否则向上翻。
    - 列表上边压住盒底 6 像素（`stick`），看起来是一体的。箭头展开时始终转 180°。

12. **公开 API**（`setXxx` 不回调，只有用户操作才回调）：
    - 属性：`items: GMOptionItem[]`、`index: number`。
    - `setItems(items)`、`setIndex(i)`（不回调）、`setOnChange(cb)`（只在用户点选且值真的变了时调）。
    - `toggle()` / `open()` / `close()`。
    - 点**已选中那一项**：只收起，不回调。
    - 收起态盒子的点击由调用方 `gu.addClick(sel.node, () => sel.toggle())` 注册。
    - 不动 `gm.version`（只加新文件和新槽，属「修」的范围，版本号由控制窗口统一升）。

13. **演示：选择页 8 行。**

    | 行 | 控件 | 内容 | 说明 |
    |---|---|---|---|
    | 1 | `ctlSelectMany` | 50 项 | 顶部，必然向下弹，验滚动 |
    | 2 | `ctlSlider` | 滑条 | 原有 |
    | 3 | `ctlStepper` | 步进 | 原有，挪位 |
    | 4 | `ctlSwitch` | 开关 | 原有，挪位 |
    | 5 | `ctlCheck` | 勾选 | 原有，挪位 |
    | 6 | `ctlSelectText` / `ctlSelectIcon` | 简单/普通/困难、星星/金币/钻石 | 并排，x = ∓150，宽 276 |
    | 7 | `ctlSelectUp` | 上/中/下 | 底部，必然向上弹 |

    - 行距 175，底部说明字 `pickNote` 移到页顶 y = -450。
    - 各自的 `setOnChange` 把结果写进 `pickNote`：`下拉 → 普通`、`物品 → 钻石`、`50 项 → 选项 45`。

14. **设置页不动。** `LySetting.ts` 齿轮旁那行「语言  中文」保持死文字，这次不换。

15. **`LyControls.prefab` 里嵌 4 个 `PfGMSelect` 实例**，根上 `cc.PrefabInfo` 的 `nestedPrefabInstanceRoots` 必须登记（28 个，全部一一对应）。

16. **图集落地**：素材侧 `ctrl.png` 2048，游戏侧 1024。**绝不跑 `tools/export-zoo-v7-plist.mjs`**（它会把 `slider_fill` 改回 `progress_fill`，还会重写 `item.png` 和旧子图 uuid）。
    - 游戏侧只加这 6 帧，其余帧一个字不动。
    - `ctrl.plist.meta`：新帧 `trimType` 写 `none`、`packable` 写 `false`。**同名子条目不能有两份**，否则引擎会拿到 border 全 0 的那份。

## 不做什么

- 不做虚拟列表、不做行复用。50 项就是 50 个节点，靠 `ScrollView` 滚。虚拟列表以后单独做。
- 不动 `LySetting`，「语言  中文」保持死文字。
- 不动已画的 25 个槽的坐标和画法；不动 `item.png` / `item.plist`。
- 不跑 `tools/export-zoo-v7-plist.mjs`。
- 不改 `CHANGELOG.md`、`gmajor/launch/GMLauncher.ts`、`extensions/gmajor/package.json`、`assets/game/config.ts`（版本号由控制窗口统一升）。
- 不改 `.cursor/rules/`、不改 `docs/临时总结/`、不动 `docs/界面组件/进度.md`。
- 不碰 `PfGMToast.ts` / `PfGMToast.prefab` / `GMUIManager.ts` 的 Toast 部分（另一窗口）。
- 不 commit、不 push（由人执行）。

## 验收标准

1. LyControls「选择」页能看到 4 个下拉框：50 项（顶部）、纯文字、带图标（并排）、向上弹（底部）。
2. 收起态显示当前项文字，右侧有箭头；带图标那个连图标一起显示。
3. 点一下展开，能看到选项；下方放不下则向上弹，不出页面边界。
4. 选中项绿底高亮，未选中项只有字。
5. 点某一项：收起、回填文字和图标、`pickNote` 写出结果。
6. 点列表外面：收起，不改选中值。
7. 展开时箭头转 180°；列表上边压住盒底 6 像素，看不出缝。
8. 50 项能滚，滚动条平时隐藏、滚动时出现；滑块圆头保持正圆不变形。
9. 皮和其它控件同一套：浅橡木框、奶油底、草地绿选中。
10. 已完成的 9 个控件表现不变。
11. 图集实画 31、预留 5；三帧 `packable` 为 false、`trimType` 为 none；meta 无重复条目。

## 实现中踩到的坑（后续补控件要注意）

1. **框架预制体不能引用 `assets/game` 资源**，但脚本可以 `applySkin` 在编辑器里贴图。漏贴就会出现「编辑器里是白图、播放时才对」的割裂。`dressSkeleton()` 解决这个。
2. **图集子帧的 id 不能换**。Creator 只在首次导入时按 `plist.meta` 的 border 生成 `capInsets`；换新 id 后 `library` 里没有对应产物，九宫格永远是 `[0,0,0,0]`。
3. **`plist.meta` 里同一个 name 不能有两份子条目**。Creator 重导入时会补一份 `packable: true` / border 全 0 的，引擎可能拿到错的那份。每次导入后要检查。
4. **嵌套预制体实例的坐标有两份**：`Node._lpos` 和 `PrefabInstance.propertyOverrides` 里的 `_lpos`，**运行时以后者为准**。只改 Node 无效。
5. **窄条不要用 `scale` 缩小**，会把高度一起缩掉。要改就改图。
6. **`gu.addClick` 的回调收到的是 `Button` 组件，不是 `EventTouch`**，拿不到 `getUILocation()`。要坐标就自己监听 `TOUCH_END`。
