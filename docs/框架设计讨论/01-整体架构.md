# 整体架构（截图整理）

来源：架构白板。四块能力域 + 后续补充的「核心绑定层」。

## 分层示意（草案）

```text
+------------------------------------------------------------------+
|  SDK（不同平台）                                                   |
|  广告 / 支付 / 货币 / Scheme / 账号登录 / 数数 / 其他               |
+------------------------------------------------------------------+
|  视图层                                                            |
|  场景 / 层级 / 弹窗 / 加载页 / 切场景 / 资源管理                    |
+------------------------------------------------------------------+
|  通用管理器                                                        |
|  对象池 / 消息 / 触屏 / 流程 / 协议 / 声音 / 配表                   |
|  下载 / 热更 / Bundle / WebSocket / 多语言 / 任务 / 定时器          |
+------------------------------------------------------------------+
|  通用组件                                                          |
|  场景组件 / 层级组件 / 弹窗 / 加载 / 气泡 / 页签                   |
|  按钮 / 滑动条 / 定高滚动 / 不定高滚动                             |
|  + 适配组件                                                        |
+------------------------------------------------------------------+
|  * 核心底层（硬约束）                                              |
|  可绑定基类 / 生命周期 / 模块注册表 / Bundle 桥接                  |
+------------------------------------------------------------------+
```

> 核心层未出现在原始架构图中，按发起方要求补入：绑定/解绑与生命周期归核心。

## 1. 通用组件

- 组件基类
- 场景 / 层级 / 弹窗 / 加载 / 气泡 / 页签
- 按钮 / 滑动条
- 定高滚动视图 / 不定高滚动视图
- **适配组件**（分辨率 / 安全区等）

## 2. 通用管理器

| 管理器 | 备注 |
|--------|------|
| 对象池 | 性能与复用 |
| 消息管理器 | 全局消息 / 事件 |
| 触屏管理器 | 输入 |
| 流程管理器 | 流程 / 状态机类编排 |
| 协议管理器 | 网络协议编解码协作 |
| 声音管理器 | 音频 |
| 配表管理器 | 配置表 |
| 下载管理器 | 下载 |
| 热更管理器 | 热更新 |
| Bundle 管理器 | 资源分包 |
| WebSocket 管理器 | 长连接 |
| 多语言 | 国际化 |
| 任务管理器 | 支持优先级 |
| 定时器管理 | 统一调度 |

## 3. 视图层

- 场景管理
- 层级管理
- 弹窗管理
- 加载页管理
- 切换场景管理
- 资源管理（与视图强相关的加载/卸载）

## 4. SDK（多平台）

- 广告 / 支付 / 货币 / 深链 Scheme
- 账号 / 登录
- 数数（分析）
- 其他：渠道、应用版本等
