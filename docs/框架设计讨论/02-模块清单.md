# 能力模块清单（截图整理）

来源：「模块列表」。这是能力面清单，不等于最终「一期必做」。

## 1. 音频模块

- 微信 / 通用音频体系
- 多分组管理

## 2. 新手引导模块

- 多引导管理
- 多边形遮罩
- 跳转到任意步骤
- 步骤可任意插入 / 删除 / 增加
- 一步一脚本

## 3. 多语言模块

- 文本 / 图片 / 节点多语言
- 可动态追加文本与图片数据
- 编辑器内预览翻译

## 4. 模块系统

- 单脚本与 MVC 架构支持
- 成熟界面管理器
- 完整生命周期与显示层级控制

## 5. 网络模块

- HTTP + WebSocket
- 可定制编解码
- 简化收发
- 可扩展传输数据结构

## 6. 资源模块

- 本地 / 远程 / 编辑器资源加载与释放
- Bundle 热更机制
- Bundle 管理器机制

## 7. 数据模块

- 数据共享（异步 / 同步）
- 类型安全的本地存储
- 数据监听（可扩展为数据绑定或本地调试）

## 8. 任务模块

- 可复用异步任务
- 任务流水线（顺序执行）

## 9. 事件模块

- 类型安全参数
- 可创建多实例事件对象
- 可「请求式」等待回调返回

## 10. 日志模块

- 多实例
- 打印级别控制
- 错误日志上传

## 11. 适配模块

- 自动屏幕适配
- 节点级适配

## 12. 其他模块

- 节点粒度暂停 / 恢复

## 与架构图的交叉

| 模块列表 | 架构图中的落点（初步映射，待决） |
|----------|----------------------------------|
| 模块系统 / 视图 | 视图层 + 通用组件 |
| 资源 / Bundle / 热更 | 资源模块 + Bundle/热更管理器 |
| 网络 / 长连接 | 网络模块 + 协议/长连接管理器 |
| 音频 | 声音管理器 / 音频模块 |
| 多语言 | 多语言管理器 / 多语言模块 |
| 任务 | 任务管理器 / 任务模块 |
| 事件 | 消息管理器 / 事件模块 |
| 适配 | 适配组件 / 适配模块 |
| 引导 / 数据 / 日志 | 独立能力，架构图未单独框出 |
