## 一句话

控件进 FFrame；本游戏换皮，不重写按钮类。

和确认框已经对齐：`GMAlert` 在 `gmajor`，确认框预制体在游戏常驻包。播放只认游戏 `bundles/Skin`，缺槽用白图。样图在 `gmajor/ui/skin`，不参与加载。接法见 [新App.md](../新App.md)。

## 三层

| 层 | 放什么 | 不放什么 |
|---|---|---|
| **FFrame / `gmajor`** | 控件脚本、预制体结构、节点约定（子节点 `label`）。样图在 `assets/gmajor/ui/skin/`，播放不加载 | 业务窗、运行时皮肤包 |
| **本游戏换皮** | `assets/game/bundles/Skin/`（Bundle `Skin`）。文件名用小写蛇形。框架会取的槽见仓库根 README | 再抄一份按钮类 |
| **独立 Widget 库** | **不做。** Q8 提过、Q9 已取消。不要第三套包 | — |

换一个 App = 换整个 `assets/game`。框架控件不用搬走。

## 皮肤

播放只认游戏 Bundle `Skin`。图的文件名是小写蛇形，种类在前：`btn_primary`、`title_bar`、`bar_bg`、`icon_close`、`panel`。按钮主题枚举仍是 `primary` 等，取图时加 `btn_`。

`assets/gmajor/ui/skin/` 放同名样图，给新游戏复制。这个目录不是 Bundle，开机不读。没有 `Skin` 包或缺某一张：该槽用内置白图，开机继续。必取清单在仓库根 README。

不要在 `GameUI/Skin` 再放一套。

## 改代码时怎么迁

控件预制体已经在 `gmajor`。换皮只改游戏 `bundles/Skin` 里的同名图。

1. 按钮 / 标题脚本和预制体在 `gmajor`，名字用 **`PfGMBtn` / `PfGMTitle`**（`Pf`=预制体，`GM`=框架）。框架弹层预制体用 `LyGMXxx`。不要 `PfBtn`、`PfFFBtn`、`GMBtn`。`GMAlert` 仍是基类。
2. `theme` 选底板和描边：`primary` / `secondary` / `warning` / `neutral` / `info`，对应文件 `btn_primary` 等。`style` 定版式：图标加文字、纯文字、纯图标（方）。图标和文字是按钮上的属性，编辑器和 `setIcon` / `setText` 改同一份。字是白色。**不 import** 游戏的 `SkinKit`。尺寸、禁用压暗写在 `PfGMBtn.ts` 顶部。按下的缩小和压暗在 `gu.addClick`，别的按钮也能用。
3. 新 App 把样图复制进自己的 `bundles/Skin`，或换成自己的同名图。缺的槽是白图。
4. `LyAlert` 仍在本游戏；`panel` 里拖框架控件。`GMAlert` 节点名不改：`body` / `btnOk` / `btnCancel` / `label`。
5. 点击仍是外层 `gu.addClick`，控件不包一层点击。
