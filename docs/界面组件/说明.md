## 一句话

控件进 FFrame；FFrame 自带默认皮；本游戏只换皮，不重写按钮类。

和确认框已经对齐：`GMAlert` 在 `gmajor`，皮可以换。[新App.md](../新App.md) 里「无皮肤包就用框架默认 / 代码绘制」是同一条。

## 三层

| 层 | 放什么 | 不放什么 |
|---|---|---|
| **FFrame / `gmajor`** | 控件脚本、预制体结构、节点约定（`setText` / `setSkin`、子节点 `label`）。**默认皮**在 `assets/gmajor/ui/skin/`（Bundle `GMSkin`） | 业务窗 |
| **本游戏换皮** | 只要盖默认槽。现在示例可以继续用默认，不必另做一套 | 再抄一份按钮类 |
| **独立 Widget 库** | **不做。** Q8 提过、Q9 已取消。不要第三套包 | — |

换一个 App = 换整个 `assets/game`。框架控件不用搬走。

## 默认皮

FFrame **有**默认皮肤。图在 **`assets/gmajor/ui/skin/`**（Bundle `GMSkin`）：`BtnPrimary`、`BtnSecondary`、`IconClose`、`TitleBar`、`Panel` 等。不要改成灰块另画一套。切图：`node tools/temp/slice-ui-sheet.mjs --write`（源 `tools/temp/ui-style/ui-sheet-v7.png`）。

- 编辑器只开框架、还没有 `assets/game`：预览用这套默认皮。
- 接了游戏但某张皮缺了：这一槽仍用默认，或按 [新App.md](../新App.md) 代码绘制。
- 本游戏 `Skin/` 有同名槽：开机换上，盖掉默认。示例仓可以继续用默认，不必再备一份。
- 默认图给框架预览引用；发行构建怎么收，按 [新App.md](../新App.md)。

## 改代码时怎么迁

默认皮已进 `gmajor/ui/skin`。还没做的是控件预制体：

1. 按钮 / 标题脚本和预制体进 `gmajor`，名字用 **`PfGMBtn` / `PfGMTitle`**（`Pf`=预制体，`GM`=框架）。框架弹层预制体用 `LyGMXxx`。不要 `PfBtn`、`PfFFBtn`、`GMBtn`。`GMAlert` 仍是基类。
2. `theme` 按颜色选底板和描边（`green` / `cream` / `yellow` / `tan` / `blue`）。`style` 定版式：图标加文字、纯文字、纯图标（方）。图标和文字是按钮上的属性，编辑器和 `setIcon` / `setText` 改同一份。字是白色。**不 import** 游戏的 `SkinKit`。尺寸、禁用压暗写在 `PfGMBtn.ts` 顶部。按下的缩小和压暗在 `gu.addClick`，别的按钮也能用。
3. 示例游戏继续贴这套默认皮。以后别的 App 要换皮，再在自己的包里盖同名槽。
4. `LyAlert` 仍在本游戏；`panel` 里拖框架控件。`GMAlert` 节点名不改：`body` / `btnOk` / `btnCancel` / `label`。
5. 点击仍是外层 `gu.addClick`，控件不包一层点击。
