## 三层

| 层 | 放什么 | 不放什么 |
|---|---|---|
| **FFrame / `gmajor`** | 控件脚本、预制体结构、节点约定（子节点 `label`） | 业务窗、运行时皮肤包、界面图 |
| **本游戏换皮** | `assets/game/bundles/Skin/`（Bundle `Skin`）。文件名用小写蛇形。框架会取的槽见仓库根 README | 再抄一份按钮类 |
| **独立 Widget 库** | **不做。** Q8 提过、Q9 已取消。不要第三套包 | — |

换一个 App = 换一个 Creator 工程；框架通过 `db://gmajor` 引用，不用搬。框架控件不用搬走。

## 皮肤

播放只认游戏 Bundle `Skin`，按 `config.skinTheme` 进 `bundles/Skin/<主题>/`。一套主题两份图集：`ctrl.png` + `ctrl.plist`（控件），`item.png` + `item.plist`（物品）。槽名是小写蛇形，种类在前：`btn_primary`、`title_bar`、`bar_bg`、`icon_close`、`panel`。按钮主题枚举仍是 `primary` 等，取图时加 `btn_`。

源图按 720×1280 的 2 倍出，留在 `FFrame-asset-line/style/<主题>/`。进游戏工程的是一半尺寸。九宫格写在 plist 子图的边上。没有 plist 的主题不加载（0.6.0 起逐张 png 路径已删除，旧的 `LegacyV3` 归档在素材仓库 `legacy/Skin-LegacyV3-game/`）。

框架仓库不带这些图。没有 `Skin` 包或缺某一张：该槽用内置白图，开机继续。必取槽名在仓库根 README。

不要在 `GameUI/Skin` 再放一套。素材和提示语放 `FFrame-asset-line/style/<主题>/`，长期脚本放 `FFrame-asset-line/tools/`。

## 改代码时怎么迁

控件预制体已经在 `gmajor`。换皮只改游戏 `bundles/Skin` 里的同名图。

1. 按钮 / 标题脚本和预制体在 `gmajor`，名字用 **`PfGMBtn` / `PfGMTitle`**（`Pf`=预制体，`GM`=框架）。框架弹层预制体用 `LyGMXxx`。不要 `PfBtn`、`PfFFBtn`、`GMBtn`。`GMAlert` 仍是基类。
2. `theme` 选底板和描边：`primary` / `secondary` / `warning` / `neutral` / `info`，对应文件 `btn_primary` 等。`+`、`−`、`×` 这种小图标用 `secondary`。确定、开始这种主操作用 `primary`。`style` 定版式：图标加文字、纯文字、纯图标（方）。图标和文字是按钮上的属性，编辑器和 `setIcon` / `setText` 改同一份。字是白色。**不 import** 游戏的 `SkinKit`。尺寸、禁用去色和禁用抖动写在 `PfGMBtn.ts` 顶部。按下的缩小和压暗在 `gu.addClick`，别的按钮也能用。`setEnabled(false)` 把底板和图标去色，再往白走三分之一，字和描边用同一套提亮。点下去不进回调，不缩小不压暗，水平抖一下再回到原位。loading 开着时跟普通点击一样不抖。步进到头的加减号同样。
3. 新 App 在自己的 `bundles/Skin/<主题>/` 放实际尺寸的 `ctrl` / `item` 图集（png + plist）。缺的槽是白图。
4. `LyAlert` 仍在本游戏；`panel` 里拖框架控件。`GMAlert` 节点名不改：`body` / `btnOk` / `btnCancel` / `label`。
5. 点击仍是外层 `gu.addClick`，控件不包一层点击。
6. 页签是 `PfGMTabs`，内容基类是 `GMTabPage`。子节点固定 `tabs`、`panel`。皮是 `tab_normal`、`tab_selected`、`panel`。不继承 `PfGMBtn`。高 72，宽按五个中文字，第一颗让过 panel 左上圆角。
7. 勾选框是 `PfGMCheck`。子节点 `box`、`mark`。皮是 `checkbox`、`checkbox_mark`。边长 48。未勾选只显示框。点击用 `gu.addClick`。
8. 开关是 `PfGMSwitch`。子节点只有一个 `face`，固定 96×48，不拉伸。皮是 `switch_off`、`switch_on`，圆钮画在图里。`value` 是布尔，`setValue` 和检查器同一份。点击用 `gu.addClick`。
9. 道具格是 `PfGMItemCell`。子节点 `bg`、`icon`、`frame`、`label`。皮是 `slot_item`、`frame_select`。底 96，图标 52，选中框 96 默认隐藏。数量字号固定 20，超过 999 显示 `999+`。用 `setIcon` / `setCount` / `setSelected`，不直接改节点。
