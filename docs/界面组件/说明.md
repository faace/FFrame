## 一句话

控件进 FFrame；本游戏换皮，不重写按钮类。

和确认框已经对齐：`GMAlert` 在 `gmajor`，确认框预制体在游戏常驻包。播放只认游戏 `bundles/Skin`，缺槽用白图。框架不带界面图。接法见 [新App.md](../新App.md)。

## 三层

| 层 | 放什么 | 不放什么 |
|---|---|---|
| **FFrame / `gmajor`** | 控件脚本、预制体结构、节点约定（子节点 `label`） | 业务窗、运行时皮肤包、界面图 |
| **本游戏换皮** | `assets/game/bundles/Skin/`（Bundle `Skin`）。文件名用小写蛇形。框架会取的槽见仓库根 README | 再抄一份按钮类 |
| **独立 Widget 库** | **不做。** Q8 提过、Q9 已取消。不要第三套包 | — |

换一个 App = 换一个 Creator 工程；框架通过 `db://gmajor` 引用，不用搬。框架控件不用搬走。

## 皮肤

播放只认游戏 Bundle `Skin`，按 `config.skinTheme` 进 `bundles/Skin/<主题>/`。一套主题两份图集：`ctrl.png` + `ctrl.plist`（控件），`item.png` + `item.plist`（物品）。槽名是小写蛇形，种类在前：`btn_primary`、`title_bar`、`bar_bg`、`icon_close`、`panel`。按钮主题枚举仍是 `primary` 等，取图时加 `btn_`。

源图按 720×1280 的 2 倍出，留在 `FFrame-asset-line/style/<主题>/`。进游戏工程的是一半尺寸。九宫格写在 plist 子图的边上。没有 plist 的主题不加载（0.6.0 起逐张 png 路径已删除，旧的 `LegacyV3` 归档在素材仓库 `legacy/Skin-LegacyV3-game/`）。

框架仓库不带这些图。没有 `Skin` 包或缺某一张：该槽用内置白图，开机继续。必取槽名在仓库根 README。

不要在 `GameUI/Skin` 再放一套。素材和提示语放 `FFrame-asset-line/style/<主题>/`，长期脚本放 `FFrame-asset-line/tools/`。

## 改代码时怎么迁

控件预制体已经在 `gmajor`。换皮只改游戏 `bundles/Skin` 里的同名图。

1. 按钮 / 标题脚本和预制体在 `gmajor`，名字用 **`PfGMBtn` / `PfGMTitle`**（`Pf`=预制体，`GM`=框架）。框架弹层预制体用 `LyGMXxx`。不要 `PfBtn`、`PfFFBtn`、`GMBtn`。`GMAlert` 仍是基类。
2. `theme` 选底板和描边：`primary` / `secondary` / `warning` / `neutral` / `info`，对应文件 `btn_primary` 等。`+`、`−`、`×` 这种小图标用 `secondary`。确定、开始这种主操作用 `primary`。`style` 定版式：图标加文字、纯文字、纯图标（方）。图标和文字是按钮上的属性，编辑器和 `setIcon` / `setText` 改同一份。字是白色。**不 import** 游戏的 `SkinKit`。尺寸、禁用去色和禁用抖动写在 `PfGMBtn.ts` 顶部。按下的缩小和压暗在 `gu.addClick`，别的按钮也能用。`setEnabled(false)` 把底板和图标去色，再往白走三分之一，字和描边用同一套提亮。点下去不进回调，不缩小不压暗，水平抖一下再回到原位。loading 开着时跟普通点击一样不抖。步进到头的加减号同样。
3. 新 App 在自己的 `bundles/Skin/<主题>/` 放实际尺寸的 `ctrl` / `item` 图集（png + plist）。缺的槽是白图。
4. `LyAlert` 仍在本游戏；`panel` 里拖框架控件。`GMAlert` 节点名不改：`body` / `btnOk` / `btnCancel` / `label`。
5. 点击仍是外层 `gu.addClick`，控件不包一层点击。
6. 页签是 `PfGMTabs`，内容基类是 `GMTabPage`。子节点固定 `tabs`、`panel`。皮是 `tab_normal`、`tab_selected`、`panel`。不继承 `PfGMBtn`。高 64。整排一样宽，`chars` 默认 5，按这么多个中文字来量，左右各留 12。左边留半个圆角直径（20），右边留一个直径（40）。一排超出这块宽度时，只横滑上面的页签条，不画滚动条；下面的板子不靠滑动换页。整颗控件窄于 360 拉回 360。标题比字数长时字缩小。点击用 `gu.addClick`。`setChars` 和检查器是同一份，小于等于 1 或带小数的值不生效。
7. 勾选框是 `PfGMCheck`。子节点 `box`、`mark`。皮是 `checkbox`、`checkbox_mark`。边长 48。未勾选只显示框。点击用 `gu.addClick`。
8. 开关是 `PfGMSwitch`。子节点只有一个 `face`，固定 96×48，不拉伸。皮是 `switch_off`、`switch_on`，圆钮画在图里。`value` 是布尔，`setValue` 和检查器同一份。点击用 `gu.addClick`。
9. 道具格是 `PfGMItemCell`。子节点 `bg`、`icon`、`frame`、`label`。皮是 `slot_item`、`frame_select`。底 96，图标 52，选中框 96 默认隐藏。数量字号固定 20，超过 999 显示 `999+`。用 `setIcon` / `setCount` / `setSelected`，不直接改节点。
10. 下拉是 `PfGMSelect`，展开时的行是 `PfGMOption`。收起态子节点固定 `bg`、`icon`、`label`、`arrow`。展开时建一块 `PfGMList`，底板用 `dropdown_list`（上边直角贴住盒子），不要换成四角圆角的 `panel`。行是 `PfGMOption`，继承 `GMListItem`。皮是 `dropdown`（收起态盒子）、`dropdown_list`（列表底板，上边直角贴住盒子）、`dropdown_item_on`（选中行）、`icon_arrow`（箭头）、`scrollbar` / `scrollbar_thumb`（滚动条槽和滑块）。收起态高 72、宽读根节点；行高 64。选项是 `GMOptionItem`（`text` + `icon`），`icon` 填物品槽名就有图。`index` 是当前项，`-1` 表示不选。`setItems` / `setIndex` 不回调，`setOnChange` 只在用户点选且值真的变了时调。点外面收起不改值。展开列表用引擎自带 `ScrollView` 滚，一屏最多 8 行；滚动条平时透明、滚动时出现、停手 0.8 秒后渐隐（`ScrollBar.enableAutoHide`）。展开方向按页面内上下余量自动选，放不下的那一侧空间大就往上翻，箭头始终转 180°。列表上边压住盒底 6 像素。收起态盒子的点击由调用方 `gu.addClick(node, () => sel.toggle())` 注册。
11. 轻提示是 `PfGMToast`，子节点 `bg`、`label`。皮是 `toast`，显示 480×72，九宫格四边各 20。中间那条横带是纯色，纵向拉伸不走样。文字单行、28 号深墨、不描边，超长缩字号不换行。调用是 `gu.toast(text)` 弹一句、`gu.toastHide()` 全部收起、`gu.setToastAnchor('top'|'center'|'bottom')` 改停靠。开机默认 `center`，锚点可以随时改，这次的值和当前不同就先收起正在显示的。最多叠 3 条、间距 12。最老的贴着停靠点，新的在最外一格；贴着停靠点的那条消失后，其余的补过去。同一句再调一次再出一条。`top` 最高点离顶 120，`bottom` 最低点离底 120，`center` 最高点在中线上方 168，新的从中线向上飘。不进弹层栈、不挡输入、不可点。队列在 `GMToastHost`，挂在 Overlay 的 `toasts` 容器上。
12. 列表是 `PfGMList`。根上的底板是 `panel`，四角都是圆角，九宫格拉伸。下拉展开列表仍用上边直角的 `dropdown_list`。子节点 `view`（Mask）→ `content`，竖条 `scrollBar` → `bar`，横条 `scrollBarX` → `bar`。`view` 和 `content` 锚点都是 (0.5, 0.5)。行基类是 `GMListItem`（没有预制体），游戏的行继承它，根上挂自己的预制体。`setItems(prefab, count)` 一次铺完，再调就先拆旧行。`setDir` 选上下或左右，`setLineCount(1)` 是单列或单行，大于 1 是网格。滚动那一边用行预制体的边长；另一边铺满整块可视区，滚动条叠在上面、不占这一边。上下滚铺满宽，左右滚铺满高，网格按个数把这一边均分。横条的槽和滑块是竖图，转到 -90° 再拉，九宫格圆头不变形。`setCenter(true)` 只在内容不满可视区时生效：关掉 `ScrollView`，`content` 的 x、y 为 0。网格没排满一行或一列时，内容只包住已有的格子，横竖一起居中。没开居中时竖向靠上、横向靠左。超出可视区时居中不生效，仍靠起点，能滚到最后一项。滚动条皮 `scrollbar`、`scrollbar_thumb`，放得下就不出，超出时滚动中出现、停手 0.8 秒后渐隐。不带下拉的盒子、箭头和选中态。点击由行自己 `gu.addClick`，列表不挂 `Button`。
13. 单选是 `PfGMRadioGroup` 和 `PfGMRadio`。组只看直接子节点，每个子节点里正好一颗圆点，子节点顺序就是 `index`，`-1` 表示不选。圆点边长 48，子节点 `ring`、`mark`，皮 `radio`、`radio_mark`。未选只显示空心圆，选中再显示实心圆点。热区是圆点的父节点（这一行）的 `contentSize`，点圆点或点行里的字都选中这一项。组用 `gu.addClick` 且 `press: 'none'`。`setIndex` 不回调，`setOnChange` 只在点到另一项时调。点已选项不取消。两个类都没有 `update()`。

## 摆控件不许压背景边框

弹窗 / 页面背景（`panel` 皮）自己有九宫格边框，内沿约等于 `border` 那圈（`panel` 是 20）。控件、说明字、列表底板**一律不许压到那圈边框上**，否则两块木框叠在一起，看起来像控件被裁掉一块。

- 演示里 `pagePick` 是 592 宽，背景内沿约 ±276。这一页所有控件左边缘统一在 **−240**，离边框留 36px。改宽度前先量一遍：`左边 = x − 宽/2`，`右边 = x + 宽/2`，两边都要落在 ±276 内。
- 展开列表（下拉、页签的 panel）比收起态更宽时，也要按同一套算，别只顾收起态。
- 两个控件并排时尤其容易踩：宽度加起来超过「内沿 × 2」就会压边框。并排改纵向排时，记得把 `x` 和宽都改回居中全宽，只改 `y` 会留下并排时代的偏移（下拉框就踩过这个，x 还是 ±150、宽 276，左右到 ±288，压进去 12px）。
