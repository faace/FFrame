## 怎么读这张表

- **Agent 可调**：有公开 REST / 托管 MCP，我能代你生成、多抽、再给你确认。
- **人工站**：要你自己点网页；我最多帮写提示词、下结果、筛图。
- **齐格**：输出是不是真的 16×16 这种游戏像素，而不是「看起来像像素」的大图。
- 价格与支付以官网为准，表里是调研日量级。
