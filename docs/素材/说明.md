# 素材

像素风怎么生成、试过什么、策划定了再怎么进游戏。  
**新窗口先看 [进度.md](./进度.md)**（做过什么 / 停在哪 / 后续）。双窗和框架进度不在本目录。

工具对照仍是调研备查，**不是**已锁定方案：

- **像素生成服务**（网站 / API / 托管 MCP）：[00-像素生成工具对照.md](./00-像素生成工具对照.md)
- **Agent skill / 切图脚本**：[像素素材工具推荐.html](./像素素材工具推荐.html)

本机训练、本机跑模型不收。通用文生图不进像素生成主表。

## 和另外几套文档的边界

| 目录 | 写什么 |
|------|--------|
| `docs/架构/` | 框架怎么用（含双窗进度，不记素材） |
| `docs/框架设计讨论/` | 框架为什么这么做 |
| `docs/策划/` | 游戏是什么、首版做哪些；定身材 / 地面建筑后回头开素材 |
| `docs/素材/` | 像素生成、试笔、进游戏前的规格 |
