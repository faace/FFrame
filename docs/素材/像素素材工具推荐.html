像素素材工具推荐

对照本工程需求整理的 AI 可调用 skill / MCP。调研日期：2026-08-18。未选定、未接入，只作选型备查。

只要 Cursor / Codex 能自己跑完：agent 写提示词、调用生图、切图、出帧。人不打开网页编辑器点按钮。PixelLab / Retro Diffusion 网页算人工产品，只放附录。费用调研同日，官方随时改价。

费用：收费 / 每天免费 / 自接 API

先分两层：Skill / 脚本本身全免费（clone 就能跑切图、校验）。账单在生图。没有「每天无限免费出真像素图」这种事。

收费 生图才花钱

  • ChatGPT Plus / Pro：Codex 内置生图，Free 套餐不能生图。生图大约按文字额度的 3–5 倍扣。
  • OpenAI Images API：设 OPENAI_API_KEY 后按张计费，不走 Plus 额度。
  • Grok：网页免费档已无生图；SuperGrok 订阅，或 xAI API 约 $0.02 / 张。
  • PixelLab：订阅约 $12–50 / 月，或 API 按次扣积分。
  • Retro Diffusion：预付积分，约 $0.01–0.18 / 张，无月费。
  • Aseprite：买断软件（MCP 只是驱动它）。

每天免费 能白用什么

  • 每天无限：本地切图 / 抠底 / 打包（各 skill 的 Python、tex-packer、cocos-asset-forge 的 mock）。你已经有 PNG 时，拆件不花钱。
  • 每天有额度、不是无限：已付费的 ChatGPT Plus/Pro、Cursor/Codex 订阅里的用量，第二天或按周刷新。
  • 不是每天刷新：PixelLab 试用约 40 次、RD 新号约 50 积分、xAI 新号约 $25，用完即止。

自接 API 能插自己的 Key

  • 最合适：cocos-asset-forge（fal / HuggingFace / 硅基流动 / ModelScope / OpenAI 兼容 / ComfyUI）。
  • Retro Diffusion、PixelLab：官方 Key + MCP，接的是他们自己的 API，不是任意模型。
  • Codex 系 skill：登录 ChatGPT，或 OPENAI_API_KEY 走 Images API。
  • sprite-gen：官方 Codex 登录 / Grok OAuth；改脚本才能换别家。

智能程度怎么打

智能程度看的是 agent 自己把活干完的程度，不是画质。画质这些 skill 都吃通用生图，普遍只是「像素风」。

档含义
高会自己规划类型/布局，生成后能校验、打分或重试，人可以几乎不盯。
中高会认对象、补缺、写覆盖报告，领域窄但闭环完整。
中有固定配方和校验，自适应弱，换规格要人先说清楚。
中低有计划文件，但目标是演示层，失败几乎不会自己改策略。

sprite-gen

必看 智能：高 GitHub Codex/Claude skill + 本地 Python · 调研时约 640 stars

功能有无说明
提示词中agent 按状态写行提示 + layout guide
AI 生成中gen --provider codex / grok
锁形象强一张底图，再按 idle / walk / mine 分行生
切图 / 帧动画强色键、连通域抽帧、manifest.json.frame_layout
可选人工策展页默认可跳过，只在要人眼挑帧时打开

原因：工人不是 8 向 RPG，按状态一行生更稳。代价：要 Python；锐度取决于通用生图。

image2-ui-asset-slicer

必看 智能：中高 GitHub Codex skill + Pillow

功能有无说明
拆件 / 切图强从整版 UI 认可复用件，网格色键或连通域
缺件重生中切不干净的由 agent 再写提示生成
Cocos中README 写可打 Cocos 包
帧动画 / 矿格无—

原因：设置 / 背包需要整图拆独立透明件，且必须是 agent 跑。代价：不是 PSD 级还原。

character-animation-creator

必看 智能：中 GitHub Codex / GPT Agent skill

功能有无说明
默认规格强64×64，和策划格子量级一致
帧动画强idle 4 / walk 6 / attack 6；attack 可当挥稿
切图 / 校验中pixel_snap、atlas 校验、行预览

原因：尺寸对口。指定只要下/侧向，不要默认 8 向 24 行。和 sprite-gen 重叠，工人线最终只留一个。

按需

agent-sprite-forge

按需 智能：高 GitHub 调研时约 3800 stars

agent 计划 → 生图 → 本地切帧。prompt-rules 强制写视角 / 网格 / 色键。矿格或 FX 不够时用 generate2dsprite。不要用它的 Godot 地图 skill。

cocos-asset-forge-mcp

按需 智能：中 GitHub 本地 MCP · 调研时约 0 stars

唯一按 Creator 导入物设计的 AI MCP：透明 PNG、.plist、.cocos-asset.json。新、要自验，不要当唯一生成源。

可跳过

layered-img-skill

可跳过 智能：中低 GitHub

计划 JSON → 绿底重生层 → 裁切。是 AI，但是演示向。UI 拆件用 image2-ui-asset-slicer。
