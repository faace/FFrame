怎么读

Agent 可调

有公开 REST / 托管 MCP。我能代你生成、多抽、筛完再给你确认。

人工站

要你点网页。我最多写提示词、下结果、帮筛。

齐格

是不是真 16×16 游戏像素，而不是「看起来像像素」的大图。

支付分档

试用和付费分开看：一家常先免绑卡试用，付费再分流。渠道以官网为准。

免绑卡可试用

注册或不注册就能生成，不用绑信用卡 / 借记卡 / PayPal。

海外主候选都在这档：PixelLab、RD、Sprite-AI、SpriteCook、SpriteLab、SpriteGen、pixie.haus。国内 Holopix、Pix Forge 也是。

RD Fixer 网页免登录、不花钱。

仅支付宝 / 微信

付费结账走国内渠道，不走海外卡。

  • Holopix：人民币会员，手机号/微信登录
  • Pix Forge：按国内点数站归入；结账页要登录后核

pixie.haus 部分地区结账会出支付宝，但主路径仍是卡 / PayPal，不进本档。

必须绑卡

不绑卡（或先买海外额度）就开不了有效生成。

  • fal image2pixel：预付美元，卡或 ACH

PixelLab / RD / Sprite-AI 等付费升级也要卡，但试用不用绑。不要和本档混。

6. 现阶段判断（主接口未拍板）

  1. 成品主路径：PixelLab（UI + 角色 + 动画）+ Retro Diffusion（矿格 / 道具 / 色板）。都要海外 Key。
  2. 国内：Holopix 抠图和像素风转换；Pix Forge 若 API 能开，当备胎。不当圣经主源。
  3. 草稿：Cursor 自带生图只出气质，必须再齐格。
  4. 免费包：只抽色板和描边。
