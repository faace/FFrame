## 第 1 期：核心底层

### 已完成

- [x] 全局单例 `ff`（`launch/FFLauncher`，模块加载即就绪）
- [x] 绑定编排：`FFBinder` load/bind/unbind、嵌套、失败回滚
- [x] Bundle 标准入口：`FFBundleEntryBase` + `registerBundleEntry` → `ff.registry`
- [x] 生命周期契约：`IFFLifecycle` / `FFBindState`（编排驱动，非节点自动调）
- [x] 业务钩子 `onInit` / `onStart` / `onRemove`（`FFComponent` 收走引擎 `onLoad` / `start` / `onDestroy`）
- [x] 事件：`FFEventManager`；基类内嵌 `on/off/emit`（`FFEventHost`，CashGo 式）
- [x] 资源门面：`IFFResource` / `FFCocosResource`（Bundle + 资源 load，回调式 + 可选进度）
- [x] 命名：`FF*` / `IFF*`；目录 `launch|event|resource|bind|ui`
- [x] UI 基类分层：`Pf→FFComponent`，`Ly→FFLayer`，`Sc→FFScene→FFLayer→FFComponent`
- [x] `ff.ui`：persist Overlay（layers + loading）、真场景切换、layer 栈、loading 令牌（D27）
- [x] `onEnter`/`onLeave`：场景默认 opacity，layer 默认 scale
- [x] Demo：`DemoHome` bind → `openScene('ScDemoHome')` → `showLayer('LyDemoPopup')` → 占用 unbind 拒绝 → `closeLayer`
- [x] 日志：直接 `console.*`（不挂 `ff.log`）
- [x] 相关 Cursor rules（命名、异步回调、缩进、早退、场景挂载等）
- [x] UI 不接入 Binder 编排：`FFComponent` 不实现 `IFFLifecycle`；节点生命周期 + `ff.ui` 覆盖（避免双生命周期）
