# GMajor 核心简介

路径：`assets/gmajor/`（按功能分子目录：`launch/` `event/` `resource/` `bind/` `ui/` `data/` `platform/`；出口仍看根 `index.ts`）。全项目必带；外围功能经 Bundle **绑定/解绑** 进入。

## 怎么启动（第 1 期示范）

1. 启动场景 `game/ScMain.scene`，脚本 `ScMain` 挂在 **Canvas 下同名空节点**（与 Camera 同级；一次性点火）
2. 核心全局单例：`import { gm, gd, gl, gu, gp } from 'gmajor'`（`GMLauncher` 模块加载时创建；`gd === gm.data`，`gl === gm.local`，`gu === gm.ui`，`gp === gm.platform`；也都挂 `window`，预览控制台可直接敲）
3. `ScMain.onStart()`：`gm.boot(game/config, onComplete, onProgress)`。`role` 默认 `gp.params.role || 'web'`（Web/Electron 由平台层填 URL query；`ScMain` 不读 URL）。常驻 `boot`（`GameUI`/`User`/`Setting`）再按 `entry[role]` 绑入口（现 `web` → `DemoHome`）。脚本不写游戏名。游戏只喊 `gp`，不嗅 `window.desktop` / `wx` / `jsb`。通道：`gp.call(name, data, onComplete)` 等回包（`msgid` 对 pending）；`gp.send` 只发。外面主动推**不**走 `gp.on`，进 `gm.events`，事件名大类前缀：平台 `Gp`（`ui-closed` → `GpUiClosed`），绑定已有 `BindReady`。听：`this.on('GpUiClosed')`。入站 JSON 转对象。无通道（预览）`call` 立刻失败、不挡开机。具名封装以后加。Electron ipc 未接。
4. `DemoHome.onBind`：只 `openScene('ScDemoHome')`（蓝底）。Alert / loading / 占用 unbind / 连点 / `createTs` / `DemoChild` 验收已过，脚本不再自动跑；预制体仍留在包里
5. `gm.ui` / `gu`：persist Overlay（`layers` + `loading` + `alerts`）；真场景 `loadScene`；切场景会 `closeAll` layer（不清 Alert）。`Ly*` / Alert 根下必有 `panel`，mask 运行时从 Overlay 模板克隆（半透、挡穿透）；进场 mask 淡入同时 panel `0→1.1→1`，内容只挂 `this.panel`。场景不套这套。`openScene` / `showLayer` 已内嵌 loading（立刻挡操作，默认 1.5s 后出字）；其它异步自己 `loadingShow`/`Hide`。`delay` 默认 1.5（`Infinity` = 一直透明），`timeout` 默认 20（`Infinity` = 不自动关）。点击用 `gu.addClick(node, cb, opts?)`（代码加 Button，编辑器不用拖）；loading 开着不进回调（Alert 上的点击除外）；`opts.lockTime` 有值才锁。列表项用 `gu.createTs(prefab, nodeParm?, initParm?)` 拿脚本句柄（自己 load Prefab；激活入树则先 `onInit` 再 `init`）。系统确认 `gu.alert('文字')` 或 `{ content, ok?, cancel? }`（基类 `GMAlert`；皮在本游戏 `GameUI`，开机预载）。核心启动把设计分辨率设成窗口逻辑像素（1 单位 = 1 像素），resize 再同步 Overlay 相机；DPI / 双窗后做
6. 视图钩子 `onEnter`/`onLeave`（`gm.ui` 调）与绑定钩子 `onInit`/`onStart`/`onRemove` 分开；不要重写引擎 `onLoad`/`start`/`onDestroy`
7. 该 Bundle 还占着场景或 layer 时 **不能 unbind**（报错说明原因）
8. 日志直接用 `console.*`
9. 数据：`gd === gm.data`（server，只许 `apply`/`sync`）；`gl === gm.local`（赋值即落盘）。`bind` 建 `gd.<包>` + `gl.<包>`，`unbind` 卸这两棵（假服数据保留）。核心不预置树；`gd.User` / `gl.Setting` 随本游戏包 bind。字段 watch：`gd.watch('User', 'gold', (n, o) => {})`，`gl` 同样；基类 `this.watch(gd|gl, 树, 字段, 回调)` 退场自动摘。只盯一层字段，`===` 没变不喊；没有树就报错。对象/数组只有整份换才喊，里面改了请 `emit`
10. 框架版本是 `gm.version`（写在 `GMLauncher`）。游戏配置只在 `game/config`：`boot` / `entry` / `alert`、游戏版本。拷贝新项目只改 `game/`。界面图在游戏 `bundles/Skin`，框架会取的槽名在仓库根 README；缺槽白图。样图在 `gmajor/ui/skin`，播放不加载

```ts
// 基类内嵌事件（listener=this，需 on{EventName}）
this.on('BindReady');
onBindReady(e) { /* e.data */ }
this.on('GpUiClosed'); // 平台主动推：大类前缀 Gp；壳 msgName ui-closed → GpUiClosed
onGpUiClosed(e) { /* e.data */ }

// 入口里开场景 / 弹窗（自动带本 Bundle 名；已内嵌 loading，不必再调）
ctx.openScene('ScDemoHome', (err) => { if (err) return console.error(err); });
ctx.showLayer('LySetting', (err) => { if (err) return console.error(err); });
gm.ui.loadingShow('sync-user'); // 其它异步才自己调；立刻挡点击，默认 1.5s 出字、20s 超时
gm.ui.loadingShow('lock-ui', { delay: Infinity, timeout: Infinity }); // 只挡不出字、不自动关
gm.ui.loadingHide('sync-user');
gu.addClick(node, () => { /* 点后 */ }); // 默认不锁
gu.addClick(node, () => { /* 点后 */ }, { lockTime: 0.3 }); // 锁住时 gu 打 [gm.ui] addClick 已锁，忽略
gu.removeClick(node);

gm.resource.load('DemoHome', 'PfDemoItem', Prefab, (err, prefab) => {
    if (err || !prefab) return console.error(err);
    const item = gu.createTs(prefab, { parent: canvas, x: 0, y: 80 }, { count: 3 }); // 返回脚本
});
this.spawn(new DemoHomeWatchProbe(), { tag: 'demoData' });
gu.alert('文字');
gu.alert({ content: '要不要？', ok: () => {}, cancel: () => {} });

// 数据
gl.Setting.bgmVolume = 0.8;
gd.sync('User', (err) => { if (err) return console.error(err); /* gd.User.gold */ });
gd.apply('User', { gold: 100 });
this.watch(gl, 'Setting', 'bgmVolume', (n, o) => { /* 当场；(n, o)；=== 相同不进 */ });
```

## 生命周期 ↔ GMBindState

由 `GMBinder` → `GMBundleEntryBase` 驱动，**不是**场景节点自动调。详注见 `GMBindState.ts`。节点侧由 `GMComponent` 在引擎回调里转成同名钩子。

| 阶段 | 钩子 | 此时 state |
|------|------|-----------|
| 未创建 | — | `Uncreated` |
| 创建 | `onInit` | → `Created` |
| 绑定中 | `onBind` → `onStart` → `onEnable` | `Binding` |
| 就绪 | （进场完成） | `Ready` |
| 解绑中 | `onDisable` → `onUnbind` → `onRemove` | `Unbinding` |
| 已销毁 | — | `Destroyed`（再次 bind 会重走 `onInit`） |

业务一般只在 `Ready` 后用功能；`Binding`/`Unbinding` 是过程态。绑定退场在 `onRemove` 前卸该入口事件与 watch。包内 `spawn` 的逻辑对象先拆。
