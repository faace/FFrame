# GMajor 核心简介

路径：`assets/gmajor/`（按功能分子目录：`launch/` `event/` `resource/` `bind/` `ui/` `data/`；出口仍看根 `index.ts`）。全项目必带；外围功能经 Bundle **绑定/解绑** 进入。

## 怎么启动（第 1 期示范）

1. 启动场景 `main/ScMain.scene`，脚本 `ScMain` 挂在 **Canvas 下同名空节点**（与 Camera 同级；一次性点火）
2. 核心全局单例：`import { gm, gd, gl } from 'gmajor'`（`GMLauncher` 模块加载时创建；`gd === gm.data`，`gl === gm.local`；三者也挂 `window`，预览控制台可直接敲）
3. `ScMain.onStart()`：按 `main/config` 的 `boot` 有序打开基础包（`User`、`Setting`）→ 再 `load`/`bind('DemoHome')`
4. `DemoHome.onBind`：`bindChild('DemoChild')`，再 `ctx.openScene('ScDemoHome')` → `ctx.showLayer('LyDemoPopup')`；随后故意 unbind（应拒绝）再 `closeLayer`
5. `gm.ui`：persist Overlay（`layers` + `loading`）；真场景 `loadScene`；切场景会 `closeAll` layer
6. 视图钩子 `onEnter`/`onLeave`（`gm.ui` 调）与绑定钩子 `onInit`/`onStart`/`onRemove` 分开；不要重写引擎 `onLoad`/`start`/`onDestroy`
7. 该 Bundle 还占着场景或 layer 时 **不能 unbind**（报错说明原因）
8. 日志直接用 `console.*`
9. 数据：`gd === gm.data`（server，只许 `apply`/`sync`）；`gl === gm.local`（赋值即落盘）。`bind` 建 `gd.<包>` + `gl.<包>`，`unbind` 卸这两棵（假服数据保留）。核心不预置树；`gd.User` / `gl.Setting` 随基础包 bind。字段 watch：`gd.watch('User', 'gold', (n, o) => {})`，`gl` 同样；基类 `this.watch(gd|gl, 树, 字段, 回调)` 退场自动摘。只盯一层字段，`===` 没变不喊；没有树就报错。对象/数组只有整份换才喊，里面改了请 `emit`
10. 两份配置：都叫 `config`。`gmajor/config`（框架版本，`gm.config`）；`main/config`（`boot`、游戏版本；加字段扩展）。拷贝新项目只改后者

```ts
// 基类内嵌事件（listener=this，需 on{EventName}）
this.on('BindReady');
onBindReady(e) { /* e.data */ }

// 入口里开场景 / 弹窗（自动带本 Bundle 名）
ctx.openScene('ScDemoHome', (err) => { if (err) return console.error(err); });
ctx.showLayer('LyDemoPopup', (err) => { if (err) return console.error(err); });

// 数据
gl.Setting.bgmVolume = 0.8;
gd.sync('User', (err) => { if (err) return console.error(err); /* gd.User.gold */ });
gd.apply('User', { gold: 100 });
this.watch(gl, 'Setting', 'bgmVolume', (n, o) => { /* 当场；(n, o)；=== 相同不进 */ });
```

## 生命周期 ↔ GMBindState

由 `GMBinder` → `GMBundleEntryBase` 驱动，**不是**场景节点自动调。详注见 `GMBindState.ts`。节点侧由 `GMComponent` 在引擎回调里转成同名钩子。

| 阶段 | 钩子 | 此时 state |
|------|------|-----------|
| 未创建 | — | `Uncreated` |
| 创建 | `onInit` | → `Created` |
| 绑定中 | `onBind` → `onStart` → `onEnable` | `Binding` |
| 就绪 | （进场完成） | `Ready` |
| 解绑中 | `onDisable` → `onUnbind` → `onRemove` | `Unbinding` |
| 已销毁 | — | `Destroyed`（再次 bind 会重走 `onInit`） |

业务一般只在 `Ready` 后用功能；`Binding`/`Unbinding` 是过程态。绑定退场在 `onRemove` 前卸该入口事件与 watch。包内 `spawn` 的逻辑对象先拆。
