# FFrame 核心简介

路径：`assets/fframe/`（按功能分子目录：`launch/` `event/` `resource/` `bind/` `ui/`；出口仍看根 `index.ts`）。全项目必带；外围功能经 Bundle **绑定/解绑** 进入。

## 怎么启动（第 1 期示范）

1. 启动场景 `main/ScMain.scene`，脚本 `ScMain` 挂在 **Canvas 下同名空节点**（与 Camera 同级；一次性点火）
2. 核心全局单例：`import { ff } from 'fframe'`（`FFLauncher` 模块加载时创建）
3. `ScMain.onStart()`：回调式 `ff.binder.loadBundle`（可带进度）→ `ff.binder.bind('DemoHome')`
4. `DemoHome.onBind`：`bindChild('DemoChild')`，再 `ctx.openScene('ScDemoHome')` → `ctx.showLayer('LyDemoPopup')`；随后故意 unbind（应拒绝）再 `closeLayer`
5. `ff.ui`：persist Overlay（`layers` + `loading`）；真场景 `loadScene`；切场景会 `closeAll` layer
6. 视图钩子 `onEnter`/`onLeave`（`ff.ui` 调）与绑定钩子 `onInit`/`onStart`/`onRemove` 分开；不要重写引擎 `onLoad`/`start`/`onDestroy`
7. 该 Bundle 还占着场景或 layer 时 **不能 unbind**（报错说明原因）
8. 日志直接用 `console.*`

```ts
// 基类内嵌事件（listener=this，需 on{EventName}）
this.on('BindReady');
onBindReady(e) { /* e.data */ }

// 入口里开场景 / 弹窗（自动带本 Bundle 名）
ctx.openScene('ScDemoHome', (err) => { if (err) return console.error(err); });
ctx.showLayer('LyDemoPopup', (err) => { if (err) return console.error(err); });
```

## 生命周期 ↔ FFBindState

由 `FFBinder` → `FFBundleEntryBase` 驱动，**不是**场景节点自动调。详注见 `FFBindState.ts`。节点侧由 `FFComponent` 在引擎回调里转成同名钩子。

| 阶段 | 钩子 | 此时 state |
|------|------|-----------|
| 未创建 | — | `Uncreated` |
| 创建 | `onInit` | → `Created` |
| 绑定中 | `onBind` → `onStart` → `onEnable` | `Binding` |
| 就绪 | （进场完成） | `Ready` |
| 解绑中 | `onDisable` → `onUnbind` → `onRemove` | `Unbinding` |
| 已销毁 | — | `Destroyed`（再次 bind 会重走 `onInit`） |

业务一般只在 `Ready` 后用功能；`Binding`/`Unbinding` 是过程态。绑定退场在 `onRemove` 前卸该入口监听。
